# 小程序工程化：分包、隐私、类型与页面测试（FE-02 / T287）

## 1. 分包（体积与首屏）

ISS-29 的遗留面：小程序 12 个页面全在主包，首次启动要下载全部代码；`lazyCodeLoading` 未开启。

### 现状

| 包 | 页面 |
|---|---|
| 主包 | 首页、账单、报修、个人中心（4 个 tab）+ 保洁工作台 + 登录 |
| `packageA` | 合同、账户余额、主题设置、通知提醒、账单详情、报修进度 |

- `pages.json` 用 `subPackages[].root = "packageA"`；所有跳转已改为 `/packageA/...`。
- `preloadRule`：首页与个人中心在 `network: all` 时预下载分包，避免第一次点开白屏。
- `manifest.json` 开启 `mp-weixin.lazyCodeLoading = "requiredComponents"`，按需注入组件。
- 构建产物：`dist/build/mp-weixin/app.json` 的 `pages` 6 条 + `subPackages` 6 条，合计 12 页。

### 为什么这样切

- tab 页不能进分包（微信限制），所以账单/报修/首页/个人中心留在主包。
- 详情页（账单详情、报修进度）使用频率低于列表，但体积占比高，进分包收益最大。
- 合同/账户/通知/主题属于低频入口，集中到同一个分包，只付一次下载成本。

## 2. 隐私授权

微信要求调用 `chooseImage`（相册/相机）、`setClipboardData`、`saveImageToPhotosAlbum`
等隐私接口前，先展示《隐私保护指引》。此前项目没有任何授权处理。

`utils/privacy.js`：

| 导出 | 作用 |
|---|---|
| `PRIVACY_ITEMS` | 实际使用的接口 + 用途（与小程序后台指引一致） |
| `privacySummary()` | 生成弹窗标题/正文/按钮文案（纯函数，可单测） |
| `installPrivacyHandler()` | `App.onLaunch` 注册 `uni.onNeedPrivacyAuthorization`，默认用 `uni.showModal` |
| `withPrivacy(action)` | 包裹隐私调用；用户取消/拒绝返回 `null`，其它错误继续抛 |

- 报修页 `chooseImage` 已改用 `withPrivacy`，拒绝时不弹二次错误。
- 平台不支持该 API（H5 / 低版本基础库）时 `installPrivacyHandler()` 返回 `false`，不抛错。

> 小程序后台的《隐私保护指引》文本仍需人工在微信公众平台填写；本任务只保证代码侧
> 有授权弹窗与用途说明。

## 3. 类型检查

`tsconfig.json` + `globals.d.ts`：

- `allowJs` + `checkJs`，覆盖 `api/**` 与 `utils/**`（不检查 `.vue`，避免与 uni 编译器冲突）。
- `types: ["@dcloudio/types"]` 提供 `uni` 全局；`globals.d.ts` 声明 Vite 注入的 `__API_BASE_URL__`。
- `npm run typecheck` 已加入 `miniprogram-ci.yml`，类型回归会阻断 PR。

修正的真实问题：

| 位置 | 问题 |
|---|---|
| `utils/request.js` | `res.data` 是 `string \| object \| ArrayBuffer`，直接读 `.accessToken` 在类型上不成立；统一 `asObject()` 收敛 |
| `utils/request.js` | 给 `Error` 挂 `statusCode`/`code`/`isNetworkError` 未声明；新增 `RequestError` typedef |
| `api/maintenance.js` | 上传响应 `JSON.parse` 后仍是 `any`；补 `data.url` 判空与返回类型 |

## 4. 页面测试

新增 `tests/pages-extra.test.mjs`：用同一套 `uni` mock 加载 Options API 脚本，覆盖此前无测试的页面。

| 用例 | 覆盖点 |
|---|---|
| 通知页未读筛选 | 只传 `unreadOnly`（不传 `false`）、列表累加、标记已读后从未读列表移除 |
| 通知页全部已读 | 角标清零、列表全标已读、提示文案 |
| 账户页 | 交易类型文案、日期格式化、空值 |
| 合同页 | 无合同时返回空数组、不抛错 |
| 主题页 | 预览样式取自主题令牌（含 mixin 计算属性） |

配套基建：

- `tests/_page-loader.mjs`：按逻辑名在 `pages/` 与 `packageA/` 之间查找页面，分包迁移不需要逐个改测试路径。
- `tests/subpackage.test.mjs`：断言主包/分包页面清单、文件存在、预下载规则、以及所有跳转目标都真实存在。
- `tests/privacy.test.mjs`：隐私条目文案、回调注册、平台降级。
