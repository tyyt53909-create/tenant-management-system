## 遗留问题

### 需要后续处理（按优先级）
1. **rooms 创建接口必失败（P0，本次烟测发现）**
   - `CreateRoomDto.buildingId` 校验 `@IsUUID('4')`，但实际楼栋 ID 为 `building-001`（seed）或 cuid（新建）
   - 影响：**无法通过 API 创建房源**，连带合同/账单等主流程无法从零走通
   - 建议：改为 `@IsString()`；同时检查 contracts 等模块是否有同类 UUID 校验
2. **收款登记接口缺失（P0）**
   - `PaymentRecord` 表已建但无任何写入接口；账单 `paidAmount/status` 只能手工改数字
   - dashboard 收入统计目前只能反映 seed/直接写库的数据
3. **小程序 baseURL 缺 `/api` 前缀（P1）**
   - `miniprogram/utils/request.js` 的 `BASE_URL` 指向 `http://localhost:3000`，所有请求将 404
   - 连带：小程序「我的报修」调 `/maintenance/my`，后端无此接口（需补）
4. **房态状态机 / 乐观锁 / 权限过滤**（T131 已记录，未动）
5. **测试覆盖率**：6 个 CRUD 模块仍无单测（buildings/contracts/bills/maintenance/meters/prepay/checkout）
