## 完成内容

### 1. 方案 A：虚拟水电表模拟器 (Virtual Water/Electricity Meter Simulator)
- ✅ **核心服务与路由 (`backend/src/modules/meters/`)**：
  - 新增 `RunSimulationDto`，支持校验三大场景枚举与约束参数（表计、楼栋、天数、自动结算、扰动比例）。
  - 实现 `MetersSimulatorService`，覆盖三大场景：
    1. `DAILY_HOURLY`：24 小时真实波峰波谷日曲线（夜间基底负荷、早高峰 07:00-09:00、日间上班离家低谷、晚高峰 18:00-23:00、深夜回落），拟真生成小时级数据点，支持未结算模式留存备结。
    2. `TIME_TRAVEL_MONTH`：30 天时间穿梭递增模拟（支持工作日 vs 周末用量上浮 35% 差异化曲线），为月度批量周期结算准备数据。
    3. `ANOMALY_TEST`：攻防与异常自检套件，全自动测试：
       - `DUPLICATE_MESSAGE_ID`（相同 messageId 幂等判重与防二次扣费）
       - `DUPLICATE_TIMESTAMP`（同一时间戳与读数设备重复上报平稳过滤）
       - `OUT_OF_ORDER`（延迟乱序到达包录入，自动标记 `[OUT_OF_ORDER]` 且不触发即时扣费）
       - `CONTRADICTORY_ROLLBACK`（读数矛盾倒走校验与 400 校验拦截）
  - 注册 `POST /meters/simulator/run` 路由，严格限制 ADMIN 权限。
- ✅ **管理后台可视化工作台 (`frontend-admin/`)**：
  - 新增 `MeterSimulatorDialog.vue` 组件，支持图形化选择场景、指定目标表计、调节扰动参数与天数，直观呈现执行概览、读数明细表与攻防自检判定报告。
  - 在 `frontend-admin/src/views/meters/index.vue` 水电表管理工具栏添加 `⚡ 虚拟表模拟器` 入口按钮并双向绑定。
- ✅ **独立 CLI 运维命令行脚本**：
  - `backend/scripts/simulate-meters.ts`
  - 支持 `npm --prefix backend run simulate:meters -- --scenario=DAILY_HOURLY` / `--scenario=TIME_TRAVEL_MONTH` / `--scenario=ANOMALY_TEST`。

### 2. 方案 B：MQTT 智能表模拟接入与规范 (IoT MQTT Specification & Mock)
- ✅ **ADR-003 架构规范 (`docs/adr/003-智能水电表MQTT协议与接入规范.md`)**：
  - 正式发布 ADR-003，规范物模型 Topic 层级（`telemetry` 上行遥测、`event` 告警、`command` 下行拉合闸控制、`command/ack` 执行确认）。
  - 制定上行遥测、下行拉闸断电（`SWITCH_OFF`）与充值复电（`SWITCH_ON`）的标准化 JSON Payload Schema。
  - 明确设备端 TLS 安全认证、Client-ID 规范及后端服务的数据映射与去重链路。
- ✅ **轻量级 MQTT Broker 服务容器 (`docker-compose.yml`)**：
  - 集成 `eclipse-mosquitto:2.0` 服务，映射 1883 TCP 端口与 9001 WebSocket 端口，配置挂载持久化存储与配置。
  - 创建 `docker/mosquitto/config/mosquitto.conf`。
- ✅ **虚拟 MQTT 物联网客户端模拟器**：
  - `backend/scripts/mqtt-meter-simulator.ts`：模拟真实硬件设备，连接 Broker 上报遥测，并主动监听下行 `SWITCH_OFF`/`SWITCH_ON` 命令，自动翻转继电器状态并回传 ACK 报文。
  - 配置 `npm --prefix backend run simulate:mqtt` 快捷命令。
