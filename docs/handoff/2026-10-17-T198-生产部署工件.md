## 完成内容

### 1. 生产环境镜像构建与编排工件
- **后端生产镜像（多阶段）**：`backend/Dockerfile`
  - `deps` -> `builder` -> `runner` 三阶段构建，非 root（`app` 用户，UID 1001）运行。
  - 构建期运行 `prisma generate`、`nest build`，并预编译 `prisma/seed.ts`（输出到 `dist-seed`），运行时移除 `ts-node` 等全量 devDependencies。
  - 清理无用架构的 Prisma 二进制引擎，远程 Registry push 压缩体积仅 118MB（严格满足 ≤ 250MB 指标）。
  - 内置容器级 Healthcheck（调用 `/api/health`）。
- **前端生产镜像（多阶段 + Nginx）**：`frontend-admin/Dockerfile`
  - Node 20 编译构建前端静态资源（接收构建参数 `VITE_API_BASE_URL`，默认 `/api` 同源代理）。
  - 基于 `nginx:1.27-alpine` 运行，以非 root `nginx` 用户监听 8080/8443。
  - 顺带完整挂载并托管静态落地页 `/landing/`。
- **Nginx 反向代理配置**：`docker/nginx-admin.conf`
  - 开启 gzip 压缩。
  - 添加 `X-Content-Type-Options: nosniff`、`Referrer-Policy: strict-origin-when-cross-origin`、`X-Frame-Options: SAMEORIGIN` 传输安全头。
  - 对 `/api/` 采用变量式反代与内嵌 DNS 动态解析（`backend:3000`），后端重启变换 IP 也能自愈。
  - SPA 路由 fallback（`try_files $uri $uri/ /index.html`），`index.html` 禁用客户端缓存，静态资源长效缓存。
- **生产环境 Docker Compose 编排**：`docker-compose.prod.yml`
  - 包含 `postgres`（16-alpine）、`redis`（7-alpine）、`migrate`（one-shot 独立运行）、`backend`、`web`（80/443）、`seed`（`--profile seed` 首次可选运行）。
  - 数据库与 Redis 仅加入内部专用网络 `internal`，**严禁向宿主机公网暴露端口**。
  - 强制生产强密码校验（未提供时 compose 启动报错拦截）。
- **自动化镜像发布工作流**：`.github/workflows/release.yml`
  - 监听 `git tag v*`，自动构建前端与后端多平台 Docker 镜像并推送到 GitHub Container Registry（GHCR），标记对应版本号、主次版本及 `latest`。
- **生产运维文档更新**：`docs/12-部署与运维.md`
  - 追加 §7：30 分钟干净机器部署指引、全量 `.env.prod` 模板、HTTPS 证书接入、微信小程序合法域名配置、发布与回滚操作指引。
