## 完成内容

### 1. API 模块按业务领域拆分与 JSDoc 规范
- 将原本单体臃肿的 `miniprogram/api/index.js` 解耦为 7 个高内聚独立领域模块：
  - `miniprogram/api/auth.js`：密码/邮箱验证码/Google 登录、邀请码绑定、用户信息获取
  - `miniprogram/api/contracts.js`：我的合同查询
  - `miniprogram/api/bills.js`：账单列表与详情
  - `miniprogram/api/maintenance.js`：报修工单查询、详情、创建与单据图片上传
  - `miniprogram/api/prepay.js`：预付账户余额与流水台账
  - `miniprogram/api/cleaning.js`：保洁房源任务列表、开始保洁、完成保洁
  - `miniprogram/api/notifications.js`：消息通知列表、未读计数、已读标记与删除
- 每个模块均包含完备的 JSDoc 参数与返回值结构注解，支持 IDE 静态类型提示。
- `miniprogram/api/index.js` 统一聚合并全量导出所有接口函数与命名空间（`api.auth`、`api.bills` 等），保持已有页面和测试 100% 向后兼容。

### 2. 统一错误码与弱网断网友好提示
- 在 `miniprogram/utils/request.js` 中完善标准业务错误码映射表（如 `AUTH_INVALID_CREDENTIALS`、`ROOM_VERSION_CONFLICT`、`PREPAY_INSUFFICIENT_BALANCE`、`BILL_ALREADY_PAID`、`COMMON_CONFLICT` 等），向用户提供直观明确的中文操作反馈。
- 弱网与网络断开优化：区分超时（`网络请求超时，请检查网络后重试`）与断网（`网络连接失败，请检查网络设置`），杜绝页面白屏或静默无反馈，并在抛出的 Error 对象中标记 `isNetworkError: true` 供上层页面重试处理。

### 3. 测试与构建验证
- 新增 `miniprogram/tests/modular-api.test.mjs`，包含模块导出、领域接口路由、错误码映射、弱网/断网 Toast 弹窗的 7 项新自动化测例。
- 小程序测试由 101 项增至 108 项，100% 全绿通过。
- `VITE_API_BASE_URL` 生产构建与 `check-artifacts.mjs` 工件健全性校验 100% 通过（12 个页面、静态资源齐全）。
