## 完成内容

### 1. 支付提供商退款与对账能力扩展
- ✅ 扩展 `PaymentProvider` 契约，支持退款申请 `createRefund`、退款查询 `queryRefund`、异步通知解密 `verifyAndParseRefundNotify`、日终账单下载 `downloadTradeBill`。
- ✅ 在 `WechatPaymentProvider` 中实现微信 API v3 退款规范（`POST /v3/refund/domestic/refunds`），支持 API v3 商户签名构造与 AEAD_AES_256_GCM 退款通知报文解密，并实现官方 CSV 对账单解析器 `parseTradeBillCsv`。
- ✅ 在 `MockPaymentProvider` 中自洽支持模拟退款、状态查询、退款回调与对账单下载（支持测试注入自定义账单以模拟单边账）。

### 2. 微信退款业务编排与财务冲正
- ✅ 暴露 `POST /api/bills/:id/payments/:paymentId/refund`（`@Roles('ADMIN')`）：
  - 校验目标收款记录存在且渠道为 `WECHAT`；
  - 校验退款金额合法且不超过原付款总额；
  - 调用微信退款通道成功后驱动财务冲正：全额退款自动触发 `BillPaymentService.voidPayment` 冲正机制，部分退款生成负向冲正记录并扣减账单实缴额 `paidAmount`；
  - 押金账单退款同步联动押金台账冲减。
- ✅ 暴露公开退款异步通知端点 `POST /api/payments/wechat/refund-notify`（`@Public()`）：
  - 验签并解密退款状态报文，登记退款完成日志。

### 3. 微信日终对账与自动补单（Reconciliation）
- ✅ 暴露 `POST /api/bills/reconciliation/wechat`（`@Roles('ADMIN')`）：
  - 下载官方微信对账单并与本地数据库 `payment_records` 交叉比对；
  - 准确识别平账（`MATCHED`）、微信单边账（`REMOTE_ONLY`）、本地单边账（`LOCAL_ONLY`）与金额不符（`AMOUNT_MISMATCH`）；
  - 支持 `autoSyncMissing: true` 时针对微信单边账自动补单入账。

### 4. 客户端与质量门禁
- ✅ 在 `miniprogram/api/bills.js` 导出 `refundWechatPayment` 与 `reconcileWechatPayments`，单测全绿。
- ✅ 重新生成 `backend/openapi.json` 与前端类型（OpenAPI 路由数增至 191 条），路由策略快照测试通过。
- ✅ 后端单测（151 文件，1411 测试通过）、前端后台单测（22 文件，112 测试通过）、小程序测试（136 测试全绿）。
