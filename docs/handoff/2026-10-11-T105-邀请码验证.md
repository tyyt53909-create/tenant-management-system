## 技术实现

### 邀请码格式

```typescript
const inviteCode = `INVITE-${Date.now()}-${Math.random().toString(36).substring(2, 8).toUpperCase()}`;

// 示例：INVITE-1697024400000-ABC123
```

**格式说明**：
- 前缀：`INVITE-`
- 时间戳：当前毫秒时间戳（确保唯一性）
- 随机码：6位大写字母数字混合

### 邀请码生成流程

```typescript
// 管理员生成邀请码
const inviteCode = await inviteCodeService.generateInviteCode(
  'admin-user-id',
  365  // 有效期365天
);

// 更新管理员用户记录
UPDATE users SET 
  inviteCode = 'INVITE-xxx',
  inviteExpiredAt = NOW() + INTERVAL '365 days'
WHERE id = 'admin-user-id';
```

### 邀请码验证流程

```typescript
// 注册时验证邀请码
const result = await inviteCodeService.validateInviteCode('INVITE-xxx');

if (result.valid) {
  // invitedBy: 邀请人的 userId
  console.log('邀请人：', result.invitedBy);
  // 继续注册流程...
}
```

**验证规则**：
1. ✅ 邀请码存在（数据库中找到）
2. ✅ 未过期（inviteExpiredAt > now）
3. ❌ 拒绝：不存在的邀请码
4. ❌ 拒绝：已过期的邀请码

### 批量生成邀请码

```typescript
// 管理员批量生成10个邀请码
const codes = await inviteCodeService.generateBatchInviteCodes(
  'admin-user-id',
  10,   // 生成数量
  365   // 有效期
);

// 返回：['INVITE-xxx-1', 'INVITE-xxx-2', ...]
```

**特性**：
- 使用延迟避免时间戳重复
- 每个邀请码独立有效期
- 适合批量分发场景

## 数据库字段使用

### User 表相关字段

| 字段 | 类型 | 说明 | 使用 |
|------|------|------|------|
| inviteCode | String? | 邀请码 | ✅ 存储生成的邀请码 |
| inviteExpiredAt | DateTime? | 过期时间 | ✅ 验证时检查 |
| invitedBy | String? | 邀请人ID | ✅ 记录邀请关系 |

**注意**：
- 邀请码存储在邀请人的记录中
- 被邀请人注册时，invitedBy 指向邀请人ID
- 一个用户可以生成多个邀请码（通过更新自己的记录）

## 使用场景

### 场景1：管理员邀请租客

```typescript
// 1. 管理员生成邀请码
const inviteCode = await inviteCodeService.generateInviteCode('admin-123');

// 2. 将邀请码发送给租客（短信/邮件）
// 3. 租客注册时输入邀请码
const validation = await inviteCodeService.validateInviteCode(inviteCode);

// 4. 验证通过，创建租客账号
if (validation.valid) {
  await createTenantUser({
    invitedBy: validation.invitedBy,
    // ...
  });
}
```

### 场景2：批量邀请

```typescript
// 管理员批量生成100个邀请码
const codes = await inviteCodeService.generateBatchInviteCodes('admin-123', 100);

// 导出到 Excel 或批量发送
codes.forEach((code, index) => {
  console.log(`邀请码 ${index + 1}: ${code}`);
});
```

### 场景3：检查邀请码状态

```typescript
// 检查管理员是否有有效邀请码
const hasValid = await inviteCodeService.hasValidInviteCode('admin-123');

if (!hasValid) {
  // 提示管理员重新生成
}
```
