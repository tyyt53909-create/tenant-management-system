## 技术问题与解决方案

### 问题1：Prisma 5.22.0 权限检查 Bug

**现象**：
```
Error: P1010: User `tenant_user` was denied access on the database `tenant_system.public`
```

**原因**：
- Prisma 5.22.0 与 PostgreSQL 16 的权限检查机制不兼容
- 即使用户有完整权限（验证可创建/删除表），Prisma CLI 仍报权限错误
- 影响 `prisma migrate dev` 和 `prisma db push`

**解决方案**：
1. 使用 `prisma migrate diff` 生成迁移 SQL
2. 通过 `docker exec` 直接执行 SQL
3. 手动插入种子数据（SQL 方式）

### 问题2：seed.ts 环境变量加载失败

**现象**：
```
error: Environment variable not found: DATABASE_URL
```

**原因**：
- seed.ts 使用 ES 模块（package.json 设置 `"type": "module"`）
- `__dirname` 在 ES 模块中不可用
- dotenv 需要明确路径

**解决方案**：
```typescript
import { fileURLToPath } from 'url';
import { dirname, resolve } from 'path';

const __filename = fileURLToPath(import.meta.url);
const __dirname = dirname(__filename);
dotenv.config({ path: resolve(__dirname, '../.env') });
```

### 问题3：字段名大小写

**现象**：
```
ERROR:  column "is_active" does not exist
```

**原因**：
- Prisma 使用 camelCase 字段名
- PostgreSQL 默认小写，但 Prisma 映射为 camelCase
- 需要使用双引号包裹：`"isActive"`

**解决方案**：
```sql
INSERT INTO buildings (..., "isActive", "createdAt", "updatedAt")
```
