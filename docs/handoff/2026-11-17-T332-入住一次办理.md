# T332｜入住一次辦理交接

從房源列表「辦理入住」選擇已登記租客的新租約或現有可辦理合同。先預覽帳單及啟用表計，錄入底數後一次確認。重送原資料必須沿用原 requestId。付款另行登記，押金未收仍可辦理。發現不可核對的舊游標或前段用量時整筆退回並保留原讀數。

部署先合併 T331 及 T330 相依鏈，再執行增量遷移。入住請求表保存持久化冪等結果以及實際入住時間，供後續計費歸屬使用。回滾時暫停新入住提交並保留資料表、房態、讀數與現有財務憑證。
