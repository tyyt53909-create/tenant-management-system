# T146 主题系统 Vue 3 迁移交接

## 改动

- 删除 `miniprogram/store/`（Vuex 模块与入口），**未引入任何状态管理依赖**。
- `utils/theme.js` 重写为 Vue 3 `reactive()` 轻量响应式模块，与 `utils/session.js`
  的"工具函数 + uni storage"模式对齐；保留全部原有工具函数与 `themeMixin`。
- `ThemeSelector.vue` 改用 `computed` 读取 `themeState`（跨组件同步），并修复
  导入路径 `../../` → `../`（原路径会跳出项目，构建必失败）。
- `pages/theme/theme.vue` 统一使用 `themeMixin` 的 `theme` 计算属性。
- `App.vue` 的 `onLaunch` 改为调用 `initTheme()`。
- 新增 `tests/theme.test.mjs`（12 项）；同步 `theme/README.md`、`QUICKSTART.md`。
- 合并 T145（含 T144）到 develop，恢复小程序可构建状态。
