## 技术实现

### 注册流程

```typescript
POST /auth/register
{
  "email": "user@example.com",
  "password": "password123",
  "inviteCode": "INVITE-xxx",
  "phone": "13800138000"  // 可选
}

// 处理流程：
1. 验证邀请码 → InviteCodeService.validateInviteCode()
2. 检查邮箱是否已注册 → prisma.user.findUnique()
3. 检查手机号是否已注册（如果提供）
4. 密码加密 → bcrypt.hash(password, 10)
5. 事务创建：
   - User 记录（role: TENANT, invitedBy）
   - Tenant 记录（关联 userId）
6. 生成 JWT Token → jwtService.generateTokens()
7. 返回 Token + 用户信息

// 响应：
{
  "accessToken": "eyJhbGc...",
  "refreshToken": "eyJhbGc...",
  "user": {
    "id": "user-123",
    "email": "user@example.com",
    "role": "TENANT"
  }
}
```

### 数据库事务保证

```typescript
await prisma.$transaction(async (tx) => {
  // 创建 User
  const user = await tx.user.create({
    data: {
      email,
      phone,
      passwordHash,
      role: 'TENANT',
      invitedBy,
      isActive: true,
    },
  });

  // 创建 Tenant（关联 User）
  await tx.tenant.create({
    data: {
      userId: user.id,
      name: email.split('@')[0],  // 初始名称
      phone: phone || '',
      email,
      emergencyContact: phone || '',
      emergencyPhone: phone || '',
    },
  });

  return user;
});
```

**事务特性**：
- User 和 Tenant 要么同时创建成功，要么同时失败
- 避免孤立的 User 记录（没有对应的 Tenant）
- 数据一致性保证

### 密码加密

```typescript
import * as bcrypt from 'bcrypt';

// 加密密码
const passwordHash = await bcrypt.hash(password, 10);
// salt rounds = 10，平衡安全性和性能

// 验证密码（登录时）
const isValid = await bcrypt.compare(password, passwordHash);
```
