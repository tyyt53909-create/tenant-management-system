## 技术亮点

### 1. 幂等性设计
使用 Prisma 的 `upsert` 操作：
```typescript
await prisma.building.upsert({
  where: { id: DEFAULT_BUILDING_ID },
  update: {},  // 已存在则不更新
  create: { ... },  // 不存在则创建
});
```

### 2. 环境变量配置
所有关键配置从环境变量读取，支持不同环境：
- 开发环境：使用默认值
- 生产环境：从 .env 读取安全配置

### 3. 安全性
- 密码使用 bcrypt 加密（salt rounds: 10）
- 不硬编码敏感信息
- 密码在控制台输出仅用于开发环境

### 4. 详细日志
- 每个步骤都有清晰的输出
- 最后输出完整摘要
- 便于排查问题
