# T165 用户质量反馈后的交互收口

## 本轮纠正

用户指出上一轮不够完整。上一轮「页面能打开、构建通过」不能证明整体 UI 与真实操作完成度，本轮因此以具体操作缺口为验收对象。

### 管理端

- 房源、租客、合同、账单加入真实详情抽屉，展示名称、状态、关联信息、时间及授权照片，提供编辑入口；未用假数据拼详情。
- 房源与账单增加状态筛选，列表使用分层档案单元；报修从旧通用表格改为工单卡片与处理队列。
- 合同、账单、预付账户、水电、退租表单改为可搜索的真实关联选择，楼栋／房源／租客／合同显示名称而非要求用户手填数据库 ID。选择房源或合同时回填关联字段，保留服务端验证。
- 使用统一资源面板区分骨架、空数据、失败与可重试状态；失败时保留已有记录，初次失败不显示假的「暂无数据」。
- 修正租客新增表单：后端 CreateTenantDto 不接收 idNumber，邮箱也不是必填；移除不受接口支持的证件输入与强制要求，不放宽后端安全规则。
- 新增合同／账单／水电表不再沿用前一次编辑的内容；合同与账单提交增加防重复保护。
- 去掉退租编辑「后端不会保存明细」的过期 UI 提示：现有接口已支持 items 更新。本轮未改结算规则或数据模型。
- 去掉全量图标注册；ECharts 改为按需图表组件并用 ResizeObserver 处理容器变化。图表块由约 1.13MB 降为约 566KB，仍有包体积提示，不以隐藏警告代替优化。

### 租客端

- 待缴筛选覆盖 PENDING / PARTIAL / OVERDUE，不再遗漏逾期或部分缴付账单。
- 合同与余额页明确区分加载、失败、重试、未开通／无记录；请求失败不显示虚假 0 元余额。
- 报修详情加入处理说明与照片；照片先带身份头下载，再用本地地址预览，不向外站发送 token。
- 服务图标改为语义对应的水滴、电路、家具、门窗等；完善次级文字对比度及骨架减弱动画。
- 密码错误提示改为凭据错误，不误报会话过期；请求增加 15 秒超时，密码框支持键盘确认登录。
- 后端本人工单查询补 photos 关系，同时保留租客归属校验，非本人工单仍为 404。
