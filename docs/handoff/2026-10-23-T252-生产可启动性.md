## 升级注意事项

- 生产/预发新增必填：`DATABASE_URL`、`JWT_SECRET`、`ENCRYPTION_KEY`、`CORS_ORIGINS`，以及 `REDIS_URL` 或 `REDIS_HOST`。旧部署升级前必须先补齐，否则会按设计拒绝启动。
- `REDIS_URL` 优先于 `REDIS_HOST/PORT`；两者同时存在时以 URL 为准。
- 生产进程不得再设置 `ADMIN_PASSWORD`/`CLEANER_PASSWORD`，初始账号应改用后续的一次性 bootstrap 命令（非目标，另立任务）。
