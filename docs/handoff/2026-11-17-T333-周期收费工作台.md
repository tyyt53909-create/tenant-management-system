# T333｜周期收费工作台交接

从管理员侧边栏「周期收费」选楼栋、填写截止时间、采集并生成预览。批次固定楼栋、业务月及截止时间。水电读数以目标读数所在业务月归档；租金按当前月锚点计算，与定时账单共用合同账期唯一键。已有的定时出账与读数自动扣费入口继续使用原设置。异常修复后先重新检查，再确认重跑。

同一 PostgreSQL 事务提交财务、游标和单项收据。进程定时领取已确认的数据库队列，使用行锁和保存点隔离相邻项目。站内通知使用相同单项的确定性去重键，在财务提交后投递；通知失败可独立重试。收款跟进展示账单当前已收及预付扣款。渠道范围为站内信。

部署先执行增量迁移并验证服务可读取历史批次。兼容回滚时保留批次和所有财务凭证，记录已确认而尚未处理的项目。用兼容版本恢复队列后才继续发起新批次。
