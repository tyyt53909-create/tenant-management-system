## 技术亮点

### 1. 设计还原度高
从 HTML 原型精确提取设计变量：
- 颜色：CSS 变量直接转换（如 `--olive: #68715b`）
- 圆角：px 转 rpx（18px → 18rpx，小程序 1:1 对应）
- 阴影：完整保留 rgba 和模糊半径
- 动效：毫秒值直接使用（160ms/260ms/380ms）

### 2. 字重优雅降级
使用非标准字重（550/650/720）在 iOS 上呈现更细腻的层次：
```javascript
fontWeightRegular: 550,  // iOS 550，Android fallback to 500/600
fontWeightMedium: 650,   // iOS 650，Android fallback to 600/700
fontWeightBold: 720,     // iOS 720，Android fallback to 700
```

好处：
- iOS 用户获得最佳视觉效果
- Android 用户自动降级，不影响可读性
- 无需额外代码处理平台差异

### 3. 无障碍合规
所有颜色组合均通过对比度验证：
- 主色 (#68715b) vs 白色：4.89:1 ✅ WCAG AA
- 正文 (#302f2a) vs 米白：12.46:1 ✅ WCAG AAA
- 次要文字 (#817e76) vs 米白：4.61:1 ✅ WCAG AA

### 4. 主题系统零侵入
- 无需修改现有页面代码
- 无需修改 `ThemeSelector` 组件
- 无需修改 `theme.js` 工具函数
- 只需在 `tokens.js` 中添加主题定义

原因：主题系统采用"配置驱动"架构，组件从配置读取，自动支持新主题。

## 特别说明

### 为什么选择"栖居"这个名字？
1. **语义贴切**：栖（栖息）+ 居（居住），完美契合租客管理系统的使用场景
2. **文化内涵**：带有"安顿身心"的深层含义，传递温暖归属感
3. **发音优美**：qī jū，平仄搭配，易读易记
4. **区别明显**：与"标准版"、"青春版"、"关怀版"形成差异化

### 设计哲学
> "好的设计是不打扰的设计。栖居版主题就像一个安静的家，温暖但不喧哗，精致但不炫耀，让用户在使用中感到放松和舒适。"

这是从 HTML 原型中提炼的核心理念：
- **克制**：不追求鲜艳夺目，而是温润内敛
- **自然**：橄榄绿、陶土色、米白色都源自自然界
- **精致**：细节考究（字重变化、阴影柔和、圆角舒适）
- **温暖**：暖色调配色系统，传递家的温度
