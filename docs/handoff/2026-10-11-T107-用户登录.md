## 技术实现

### 登录流程

```typescript
POST /auth/login
{
  "identifier": "user@example.com",  // 邮箱或手机号
  "password": "password123"
}

// 处理流程：
1. 查询用户（邮箱 OR 手机号）→ prisma.user.findFirst()
2. 检查用户是否存在 → 不存在返回 401
3. 检查用户是否激活 → 未激活返回 403
4. 验证密码 → bcrypt.compare(password, passwordHash)
5. 密码错误返回 401
6. 更新最后登录时间 → prisma.user.update({ lastLoginAt })
7. 生成 JWT Token → jwtService.generateTokens()
8. 返回 Token + 用户信息

// 响应：
{
  "accessToken": "eyJhbGc...",
  "refreshToken": "eyJhbGc...",
  "user": {
    "id": "user-123",
    "email": "user@example.com",
    "phone": "13800138000",
    "role": "TENANT"
  }
}
```

### 支持邮箱或手机号登录

```typescript
const user = await this.prisma.user.findFirst({
  where: {
    OR: [
      { email: dto.identifier },
      { phone: dto.identifier },
    ],
  },
});
```

**优点**：
- 用户可以用邮箱或手机号登录
- 前端只需一个输入框
- 灵活且用户友好

### 密码验证

```typescript
const isPasswordValid = await bcrypt.compare(dto.password, user.passwordHash);
if (!isPasswordValid) {
  throw new UnauthorizedException('邮箱/手机号或密码错误');
}
```

**安全特性**：
- 使用 bcrypt.compare 验证密码
- 错误消息模糊（不透露具体是邮箱还是密码错误）
- 防止用户枚举攻击

### 更新最后登录时间

```typescript
await this.prisma.user.update({
  where: { id: user.id },
  data: { lastLoginAt: new Date() },
});
```

**用途**：
- 跟踪用户活跃度
- 安全审计
- 异常检测（长时间未登录）

## 错误处理

### 401 Unauthorized

**场景**：
- 用户不存在
- 密码错误

**返回消息**：
```json
{
  "statusCode": 401,
  "message": "邮箱/手机号或密码错误"
}
```

**设计理由**：
- 模糊错误信息，防止用户枚举
- 攻击者无法确定是邮箱还是密码错误

### 403 Forbidden

**场景**：
- 账号已被禁用（isActive = false）

**返回消息**：
```json
{
  "statusCode": 403,
  "message": "账号已被禁用"
}
```

**设计理由**：
- 明确告知用户账号状态
- 与认证失败（401）区分
