## 技术实现

### JWT Payload 结构

```typescript
export interface JwtPayload {
  sub: string;        // userId
  role: string;       // UserRole (ADMIN, CLEANER, TENANT)
  buildingId?: string; // 可选，租客绑定的楼栋
}
```

### Token 生成流程

```typescript
// 1. 生成 Token 对
const tokens = await jwtAuthService.generateTokens({
  sub: 'user-123',
  role: 'ADMIN',
  buildingId: 'building-001',
});

// 返回
{
  accessToken: 'eyJhbGc...',  // 15分钟过期
  refreshToken: 'eyJhbGc...',  // 7天过期
}
```

### 路由保护使用

```typescript
@Controller('rooms')
export class RoomsController {
  @UseGuards(JwtAuthGuard)
  @Get()
  findAll(@Request() req) {
    // req.user = { userId, role, buildingId }
    console.log(req.user);
  }
}
```

### Token 验证流程

1. 客户端在 Header 中发送 Token：`Authorization: Bearer <token>`
2. JwtAuthGuard 拦截请求
3. JwtStrategy 提取并验证 Token
4. JwtStrategy.validate() 检查用户存在且激活
5. 用户信息附加到 `request.user`
6. 请求继续到 Controller

### Refresh Token 使用

```typescript
// 使用 Refresh Token 获取新的 Access Token
const newAccessToken = await jwtAuthService.refreshAccessToken(
  refreshToken,
  { sub: 'user-123', role: 'ADMIN' }
);
```

## 配置说明

### 环境变量

```env
# JWT Configuration
JWT_SECRET=your-jwt-secret-change-this-in-production
JWT_ACCESS_EXPIRY=15m
JWT_REFRESH_EXPIRY=7d
```

**安全建议**：
- 生产环境使用强随机密钥（至少32字符）
- 定期轮换密钥
- 不要将密钥提交到版本控制

### Access Token vs Refresh Token

| Token类型 | 有效期 | 用途 | 存储位置 |
|----------|--------|------|----------|
| Access Token | 15分钟 | API 请求认证 | 内存（前端） |
| Refresh Token | 7天 | 刷新 Access Token | HttpOnly Cookie |

**设计理由**：
- Access Token 短期有效，减少泄露风险
- Refresh Token 长期有效，避免频繁登录
- 刷新机制平衡安全性和用户体验

## 遇到的问题与解决

### 问题1：npm 依赖安装失败

**现象**：
```
npm error code ENOTEMPTY
npm error syscall rmdir
```

**原因**：
- node_modules 目录冲突
- Prisma engines 安装问题

**解决方案**：
```bash
npm install --force
```

### 问题2：ES 模块导入问题

**现象**：
```
TS2307: Cannot find module './jwt.service'
```

**原因**：
- package.json 设置 `"type": "module"`
- 需要显式 .js 扩展名

**解决方案**：
```typescript
import { JwtAuthService } from './jwt.service.js';
import { PrismaModule } from '../prisma/prisma.module.js';
```

### 问题3：TypeScript 类型严格检查

**现象**：
```
Type 'string | undefined' is not assignable to type 'string'
```

**原因**：
- configService.get() 返回可能为 undefined
- Passport Strategy 要求 secretOrKey 为 string

**解决方案**：
```typescript
secretOrKey: configService.get('jwt.secret') || 'fallback-secret',
```
