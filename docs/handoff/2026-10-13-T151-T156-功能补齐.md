## 本轮发现并修复的缺陷
1. **多个列表页必然 400**（阻断）：视图把空表单原样展开为 `?status=&billType=`，
   后端 `forbidNonWhitelisted` 直接拒绝 —— `/bills` 与 `/checkout` 首屏永远加载失败。
   已在请求层统一剔除空参数（一处收敛）。
2. **checkout PATCH 不落库明细**：传 items 返回 200 但明细不变，编辑扣款项静默失效。
   已改为「提供即全量替换」并同事务。
3. **unreadOnly=false 被当成 true**：`@Type(() => Boolean)` 把字符串 `"false"` 转成 true。
   已改用 `@Transform(({ value }) => value === true || value === 'true')`。
4. **邀请码可无限复用**（上一轮末发现）：注册后未清空，与 docs/03 §4.1 冲突。已改为一次性。
