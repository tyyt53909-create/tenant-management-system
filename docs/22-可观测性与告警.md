# 可观测性与告警（OPS-04 / T277）

> 目标：出问题能看见、能定位、能被告知。指标与日志优先，外部平台可后接。

## 1. 指标

端点：`GET /api/metrics`（Prometheus 文本格式，`text/plain; version=0.0.4`）。

访问控制：

| 环境 | `METRICS_TOKEN` | 行为 |
|---|---|---|
| 任意 | 已设置 | 必须 `Authorization: Bearer <token>` 或 `?token=`，否则 401 |
| production / staging | 未设置 | 404（不暴露） |
| 其他（dev/test） | 未设置 | 允许匿名抓取 |

指标清单：

| 指标 | 类型 | 标签 | 说明 |
|---|---|---|---|
| `app_http_requests_total` | counter | method, route, status | 按模板路由统计，避免 ID 高基数 |
| `app_http_request_duration_seconds` | histogram | method, route | 桶 0.05/0.1/0.3/1/3/5/10 |
| `app_scheduler_runs_total` | counter | job, status | status: SUCCESS/PARTIAL/FAILED/SKIPPED |
| `app_bills_overdue` | gauge | — | 每日任务后的逾期未缴清账单数 |
| `app_process_uptime_seconds` | gauge | — | 进程运行时长 |
| `app_process_resident_memory_bytes` | gauge | — | 进程 RSS |

- 不引入 prom-client；实现见 `common/metrics/metrics.registry.ts`。
- 采集器部署在 docker-compose/网关侧，不在仓库内配置。

## 2. 日志

- HTTP 访问日志：`logging/http-logger.ts`（pino），包含 requestId、方法、路径、状态、耗时。
- 异常日志：`AllExceptionsFilter` 统一输出 `requestId + 摘要`，不打印请求体/个资。
- 结构化字段沿用 `requestId`，与响应头 `X-Request-Id` 对齐。

## 3. 告警

`AlertService` 通过 `ALERT_WEBHOOK_URL` 发送 JSON：

```json
{
  "title": "定时任务部分失败",
  "severity": "error",
  "message": "daily-jobs 有 2 个子任务失败",
  "service": "tenant-management-system",
  "timestamp": "2026-10-25T00:00:00.000Z",
  "dedupeKey": "scheduler:daily-jobs:PARTIAL",
  "context": { "job": "daily-jobs", "status": "PARTIAL" }
}
```

- 同一 `dedupeKey` 在 `ALERT_MIN_INTERVAL_MS`（默认 60s）内只发一次。
- 未配置 URL 时只写 `WARN` 日志，不阻塞主流程；网络错误/超时（5s）同样只记日志。
- 触发点：
  - HTTP 5xx（`AllExceptionsFilter`，context 只含 requestId/method/path/status）；
  - 定时任务 `FAILED` / `PARTIAL`。

## 4. 定时任务真实性

- `JobRunStatus` 新增 `PARTIAL`：子任务有失败但任务本体跑完时记录，不再伪装 `SUCCESS`。
- 全量失败：`FAILED` + 错误摘要；未抢到锁：`SKIPPED`。
- 咨询锁事务超时由 `SCHEDULER_LOCK_TTL_SECONDS`（默认 900）控制，必须大于最长任务耗时。

## 5. 已知边界

- 未接入 Sentry/OpenTelemetry；错误追踪目前是「结构化日志 + webhook」。
- 指标只保存在进程内，重启归零；需要长期存储时由 Prometheus 抓取。
- 告警规则（5xx 比例、逾期率、备份失败）在 OPS-09 配置；本任务只提供出口。
- 多实例下 `/metrics` 要分别抓取各实例（OPS-06）。
