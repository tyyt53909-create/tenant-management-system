# 报修工单时间线与双向沟通（COM-03 / T283）

## 1. 数据

`maintenance_messages`（按工单级联删除）：

| 字段 | 说明 |
|---|---|
| type | `MESSAGE` 双方留言；`SYSTEM` 系统事件 |
| authorId / authorRole | 留言作者；系统事件为 null / SYSTEM |
| body | 文本（≤2000 字），按创建时间正序展示 |

系统事件来源：

- 创建工单：`提交报修`
- 状态变更：`状态 SUBMITTED → ACKNOWLEDGED`
- 派单：`派单给 <userId>`
- 填写处理结果：`填写处理结果`

## 2. 接口

| 方法 | 路径 | 角色 |
|---|---|---|
| GET | `/maintenance/:id/messages` | ADMIN 任意；TENANT 仅自己的工单 |
| POST | `/maintenance/:id/messages` | 同上；`{ body }` |

- 租客越权一律 404（不暴露存在性）。
- 留言不触发额外通知；如需实时提示，可在后续把消息纳入通知中心/WebSocket（T282 通道已具备）。

## 3. 前端

- 管理后台「处理报修」弹窗内展示时间线：系统事件灰底、双方留言白底。
- 输入框发送后追加到列表，不刷新整页。
- 删除工单会级联删除时间线（数据库外键 ON DELETE CASCADE）。

## 4. 已知边界

- 留言不支持附件/富文本；照片仍走工单照片表。
- 未做已读回执与未读计数（通知中心另行处理）。
- 小程序端租客留言待 FE-02 接入。
