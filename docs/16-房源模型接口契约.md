# 房源模型接口契约 v1

> 本文件是 T221～T227 的共享契约。任何 subagent 若需要改動本契約，必須先停止並回報整合者。
> 前端可先用 `frontend-admin/src/utils/__fixtures__/spaceModel.fixture.ts` 開發；後端完成後再切換 API。

---

## 1. 範圍

本契約覆蓋：

- 樓棟空間視圖 `GET /buildings/:id/space`
- 樓層平面圖 `GET /buildings/:id/floor-plans`
- 樓層平面圖編輯 `PUT /buildings/:id/floor-plans/:floor`
- 模板產生 `POST /buildings/:id/floor-plans/:floor/template`
- ADMIN / CLEANER / TENANT / PUBLIC 的角色投影

不在本契約內：

- glTF / SketchUp / Revit 模型匯入
- 歷史快照與時間軸
- 家具、材質、室內建模

---

## 2. 座標系

- 每層平面原點在左上角。
- `x` 向右，`y` 向下。
- 3D 將 `y` 映射為 `z`，樓層向上挤出。
- 單位是抽象單位，不是公尺；renderer 只負責縮放。
- `AUTO` 幾何由後端產生；前端保留 fallback，只用於 API 失敗或離線 fixture。

## 3. `SpaceModel` JSON

```ts
type SpaceView = 'ADMIN' | 'CLEANER' | 'TENANT' | 'PUBLIC';

type SpaceState =
  | 'OCCUPIED'
  | 'RESERVED'
  | 'RENTABLE'
  | 'PENDING_CLEAN'
  | 'CLEANING'
  | 'MAINTENANCE'
  | 'UNKNOWN';

type SpaceShape =
  | { kind: 'RECT'; x: number; y: number; width: number; depth: number }
  | { kind: 'POLYGON'; points: [number, number][] };

interface SpaceAlert {
  type: 'OVERDUE' | 'EXPIRING' | 'REPAIR';
  label?: string;
  severity?: 'info' | 'warning' | 'danger';
}

interface SpaceCapabilities {
  canSeeTenant: boolean;
  canSeeRent: boolean;
  canOperateStatus: boolean;
  canOperateCleaning: boolean;
}

interface SpaceRoom {
  id: string;
  roomNumber: string;
  floor: number;
  shape: SpaceShape;
  state: SpaceState;
  alerts: SpaceAlert[];
  version: number;
  unplaced?: boolean;

  // 由後端依角色投影，可能不存在
  tenantName?: string;
  lease?: {
    status: string;
    rentAmount: number;
    startDate: string;
    endDate: string;
  };
}

interface SpaceFloor {
  floor: number;
  level: number;                 // 0 = 最低層
  layoutMode: 'AUTO' | 'AUTHORED';
  width: number;
  depth: number;
  rooms: SpaceRoom[];
}

interface SpaceSummary {
  total: number;
  occupied: number;
  reserved: number;
  rentable: number;
  pendingClean: number;
  cleaning: number;
  maintenance: number;
  unknown: number;
  occupancyRate: number;
  rentableRate: number;
}

interface SpaceModel {
  building: {
    id: string;
    name: string;
    address?: string;
    floors: number;
  };
  view: SpaceView;
  layoutMode: 'AUTO' | 'AUTHORED' | 'MIXED';
  capabilities: SpaceCapabilities;
  floors: SpaceFloor[];
  summary: SpaceSummary;
  generatedAt: string;
}
```

### 幾何規則

- `AUTO`：後端依房號自然排序，依房間數自動選擇 2～8 欄，盡量讓樓層平面接近方形，必要時折行。
- `AUTHORED`：使用 `RoomShape`；找不到 shape 的房間標記 `unplaced: true`，放在樓層尾端，不得靜默消失。
- 同一棟樓可以有 `MIXED`：部分樓層 AUTO，部分樓層 AUTHORED。
- `polygon` 的點按順序連接，最後一點自動接回第一點。

## 4. 狀態映射

| `Room.status` | `Room.cleanStatus` | `SpaceState` |
|---|---|---|
| `OCCUPIED` | `CLEAN` | `OCCUPIED` |
| `RESERVED` | `CLEAN` | `RESERVED` |
| `VACANT` | `CLEAN` | `RENTABLE` |
| `VACANT` | `PENDING_CLEAN` | `PENDING_CLEAN` |
| `VACANT` | `CLEANING` | `CLEANING` |
| `MAINTENANCE` | `CLEAN` | `MAINTENANCE` |
| 其他組合 | 其他組合 | `UNKNOWN` |

`OCCUPIED` / `RESERVED` / `MAINTENANCE` 優先保留房態；只有 `VACANT` 才依清潔狀態細分。

---

## 5. 角色投影

| 能力 | ADMIN | CLEANER | TENANT | PUBLIC |
|---|---|---|---|---|
| 樓層骨架 | 全部 | 有任務的樓層 | 自己樓層 | 有可租房源的樓層 |
| 房間 | 全部 | 待清潔／清潔中 | 自己房間 | 可出租 |
| 租客姓名 | 是 | 否 | 只看自己 | 否 |
| 租金／合約 | 是 | 否 | 只看自己 | 否 |
| 房態操作 | 是 | 否 | 否 | 否 |
| 清潔操作 | 是 | 是 | 否 | 否 |
| 3D | 是 | 否（用 2D） | 否（用 2D） | 可選 |

### 安全紅線

1. 投影必須在後端完成。
2. 不得先回傳全量資料，再由前端 CSS / v-if 隱藏。
3. CLEANER 不得取得其他房間的租客、租金、房態。
4. TENANT 不得取得其他房間的佔用狀態。
5. PUBLIC 不得取得租客、租金、內部備註。

## 6. 資料模型

```prisma
model FloorPlan {
  id            String   @id @default(cuid())
  buildingId    String
  building      Building @relation(fields: [buildingId], references: [id])
  floor         Int
  width         Float
  depth         Float
  backgroundUrl String?
  version       Int      @default(0)
  createdAt     DateTime @default(now())
  updatedAt     DateTime @updatedAt
  shapes        RoomShape[]

  @@unique([buildingId, floor])
  @@index([buildingId])
  @@map("floor_plans")
}

model RoomShape {
  id          String    @id @default(cuid())
  floorPlanId String
  floorPlan   FloorPlan @relation(fields: [floorPlanId], references: [id], onDelete: Cascade)
  roomId      String?   @unique
  room        Room?     @relation(fields: [roomId], references: [id])
  kind        ShapeKind @default(RECT)
  x           Float
  y           Float
  width       Float
  depth       Float
  polygon     Json?
  rotation    Float     @default(0)
  createdAt   DateTime  @default(now())
  updatedAt   DateTime  @updatedAt

  @@index([floorPlanId])
  @@map("room_shapes")
}

enum ShapeKind {
  RECT
  POLYGON
}
```

`version` 用於編輯器樂觀鎖；`roomId` 可為空，允許先排版再綁定房間。

## 7. API

```text
GET  /buildings/:id/space
     → 依 JWT role 回傳 SpaceModel
GET  /buildings/:id/floor-plans          ADMIN
PUT  /buildings/:id/floor-plans/:floor   ADMIN
POST /buildings/:id/floor-plans/:floor/template  ADMIN
```

### 錯誤行為

- 未登入：`401`
- 非 ADMIN 呼叫 floor-plans：`403`
- 樓棟不存在：`404`
- 編輯版本衝突：`409`
- 房間已被其他 shape 綁定：`409`
- 同一樓層重複建立 floor plan：`409`
