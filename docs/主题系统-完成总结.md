## 🚀 如何使用

### 1. 安装依赖
```bash
cd miniprogram
npm install
```

### 2. 在页面中使用

**方法 A - 使用 Mixin（推荐）**:
```vue
<script>
import { themeMixin } from '@/utils/theme.js'
export default {
  mixins: [themeMixin],
  // 现在可以使用 this.$colors, this.$typography 等
}
</script>
```

**方法 B - 使用 CSS 变量**:
```css
.card {
  background-color: var(--color-bg-primary);
  padding: var(--spacing-lg);
}
```

**方法 C - 使用工具类**:
```html
<view class="card shadow-sm rounded-lg p-lg">
  <text class="text-lg font-bold text-primary">标题</text>
</view>
```

### 3. 切换主题
- 进入"个人中心"（需要添加入口）
- 点击"主题设置"
- 选择喜欢的主题

## 🎨 设计理念

### 标准版 (Standard)
- **目标用户**: 25-50岁，大部分用户
- **设计原则**: 简洁、清晰、专业
- **配色**: 蓝灰色系，沉稳可靠
- **字体**: 标准大小，易读性好

### 青春版 (Youth)  
- **目标用户**: 18-30岁，年轻租客
- **设计原则**: 活力、时尚、个性
- **配色**: 紫色渐变，充满活力
- **字体**: 稍大一些，更现代

### 关怀版 (Care)
- **目标用户**: 50+岁，中老年用户
- **设计原则**: 易用、清晰、舒适
- **配色**: 高对比度，纯黑文字
- **字体**: 增大40%，更易阅读
- **间距**: 增大50%，更易点击
- **特点**: 减少干扰，简化操作

### 夜间模式 (Dark)
- **适用场景**: 夜晚、暗光环境
- **配色**: 深色背景 + 浅色文字
- **特点**: 护眼，省电

## 💡 最佳实践

1. **优先使用 CSS 变量** - 性能最好，代码简洁
2. **关键样式用 Mixin** - 需要动态计算时
3. **布局用工具类** - 快速开发
4. **关怀版特别注意**:
   - 按钮高度至少 88rpx
   - 字体大小自动增大
   - 减少复杂交互
   - 提供明确的视觉反馈
