## 🔧 技术亮点

### 1. 关键设计模式

**乐观锁（Optimistic Locking）**：
```prisma
model Room {
  version Int @default(0)  // 防止并发修改房态冲突
}
```

**自关联（Self-Relation）**：
```prisma
model Contract {
  renewedFromId String? @unique
  renewedFrom Contract? @relation("ContractRenewal", ...)
  renewedTo Contract? @relation("ContractRenewal")
}
```

**级联删除（Cascade Delete）**：
```prisma
model ContractAttachment {
  contract Contract @relation(..., onDelete: Cascade)
}
```

### 2. 数据完整性

- 金额统一使用 Int（分为单位），避免浮点数精度问题
- 外键关系完整，保证引用完整性
- 唯一约束防止数据重复
- 索引优化查询性能

### 3. 可扩展性

- JSON 字段存储灵活数据（facilities, metadata, snapshot）
- 预留表为第二阶段功能做准备
- 枚举值清晰，易于扩展
