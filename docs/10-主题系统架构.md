## 🔄 数据流向

### 1. 初始化流程

```
App 启动 
  → App.vue onLaunch()
  → store.dispatch('init')
  → store.dispatch('theme/initTheme')
  → 从 localStorage 读取 theme 和 darkMode
  → 更新 Vuex state
  → 页面使用 themeMixin 自动获取最新主题
  → 渲染完成
```

### 2. 切换主题流程

```
用户点击主题选项
  → ThemeSelector.vue selectTheme()
  → store.dispatch('theme/changeTheme', themeName)
  → 验证主题是否存在
  → 更新 Vuex state.currentTheme
  → 保存到 localStorage
  → 触发 Vuex getters 重新计算
  → 所有使用 themeMixin 的组件自动重新渲染
  → 显示切换成功提示
  → 完成
```

### 3. 切换夜间模式流程

```
用户切换夜间模式开关
  → ThemeSelector.vue toggleDarkMode()
  → store.dispatch('theme/toggleDarkMode')
  → 更新 Vuex state.isDarkMode
  → 保存到 localStorage
  → Vuex getter 'theme' 自动合并夜间模式颜色
  → 组件自动重新渲染
  → 显示切换成功提示
  → 完成
```

- ✅ 未使用的主题不占用内存
- ✅ 轻量级设计

## 🔌 扩展性

### 添加新主题

1. 在 `theme/tokens.js` 添加主题配置
2. 在 `themeList` 中注册
3. 无需修改其他代码
4. 自动支持切换

### 添加新的设计 Token

1. 在 `theme/tokens.js` 的主题对象中添加
2. 在 `app.css` 中添加对应的 CSS 变量
3. 在 `utils/theme.js` 的 Mixin 中暴露（可选）
4. 全局可用

### 添加主题变体

可以轻松添加：
- 节日主题（春节、圣诞等）
- 品牌主题（企业定制）
- 无障碍主题（色盲友好）
- 极简主题（减少视觉元素）

## 🛡️ 兼容性保障

### 降级策略

如果浏览器不支持 CSS 变量：
- 使用硬编码的默认值
- 主题切换功能降级为标准版
- 核心功能不受影响

## 🎯 总结

主题系统采用**分层架构**，清晰的职责划分：

1. **数据层**：设计 Token 定义
2. **业务逻辑层**：Vuex 管理状态
3. **样式层**：CSS 变量渲染
4. **UI 层**：组件使用主题

- 🎨 支持多套主题

- 💾 自动持久化
