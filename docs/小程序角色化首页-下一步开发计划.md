# 小程序角色化首页：续做计划

原计划见历史提交 `75f3936`。本记录以 `develop` 基线 `3c554ab` 为准；旧计划中的运行版本、路径、测试账号和里程碑日期不再作为开发依据。运行与分包口径见 [11-小程序构建与配置](./11-小程序构建与配置.md)、[32-小程序工程化](./32-小程序工程化.md)。

## 本轮移植范围

- 租客保留首页居所位置图，账单待缴数按分页总数汇总。同日多条日历事件可分别进入分包详情；服务入口按租客能力开关展示。
- `ADMIN` 和 `PROPERTY_MANAGER` 进入管理工作台，显示已有工单 API 返回的分组总数。物业经理只看后端授权楼栋；列表和详情均沿用后端权限。从工单详情返回工作台时保留筛选。
- `CLEANER` 仍直达保洁工作台，原有清洁流程不变。其他员工角色暂由网页管理后台承接。
- 下拉和返回首页会更新数据。加载、空结果和失败状态分别显示，失败时保留当前页面已成功加载的数据。

## 本轮验收（2026-11-18）

- Node 22 本地运行：后端编译及 lint 通过，小程序类型检查、172 个测试、H5 与微信构建及产物检查通过。
- 独立 PostgreSQL 16 完整迁移后，后端 83 个 E2E 用例通过。全量单测首次 1717/1719，两个超时的鉴权用例与 CORS 共 60 个用例单独复跑通过；未将全量首跑记为通过。
- H5 手机尺寸：租客位置图与账单、报修、通知分包；管理员和物业经理工作台。两栋楼验收样本中管理员待派工数为 2、物业经理为 1；物业经理访问本楼栋详情返回 200、其他楼栋返回 403，从详情返回时保留筛选；保洁直达工作台且没有底部标签栏，已验证接单和完成清洁，数据库状态为 `CLEAN`。
- 本计划的索引和元信息已核对。正式文档门禁未运行，当前工作区未安装脚本依赖 `glob`。
