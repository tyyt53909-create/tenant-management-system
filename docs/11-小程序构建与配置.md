# 小程序构建与配置（T145）

## 安装与本地开发

```bash
cd miniprogram
npm ci
cp .env.example .env.local
npm test
npm run dev:h5
```

默认 H5 开发监听 `127.0.0.1`。微信开发编译：`npm run dev:mp-weixin`，开发者工具导入 `dist/dev/mp-weixin`。

## 工具链

- uni-app 各直接依赖使用官方已发布 Vue3 非 alpha 发行版本 `3.0.0-5020620260917001`，不是不存在的裸 3.0.0。当前 `vue3` tag 已指向要求 Node >=22.12 的新 alpha，为保持项目 Node20 基线，本任务不采用它。
- Vue 3.4.21、Vite 5.2.8 对齐该发行版的 compiler/peer 依赖；依赖锁文件随代码提交。
- `scripts/uni.mjs` 跨平台设置绝对 `UNI_INPUT_DIR`，保留根目录 pages/API/utils 结构。
- `main.js` 导出 `createSSRApp`，`index.html` 供 H5 使用；`uniStatistics.enable=false`，不主动启用统计。
- 本地 PNG 静态资源可通过 `npm run generate:icons` 重复生成，无第三方图标授权依赖。

## 公开 API 地址

`VITE_API_BASE_URL` 是编译进客户端的公开地址，不能放密钥或密码。

- 开发默认 `http://localhost:3000/api`；微信真机 localhost 指向手机，须改为局域网电脑地址或测试 HTTPS 域名。
- 生产构建必须显式提供非 localhost 的 HTTPS 完整地址，带后端 `/api` 前缀。不允许凭证、query、hash；缺失或不合法会阻止构建。
- `.env.local`、`.env.production` 被 gitignore 排除；`.env.example` 只含公开示例。
- 微信还需实际 AppID、合法 request 域名及证书。项目保留空 AppID，开发者工具内使用自己的账号配置，不凭空填写。

```bash
VITE_API_BASE_URL=https://你的实际域名/api npm run build:mp-weixin
VITE_API_BASE_URL=https://你的实际域名/api npm run build:h5
npm run check:artifacts
```

微信导入 `dist/build/mp-weixin`；H5 输出 `dist/build/h5`，使用 hash 路由。CI 用 `https://api.example.test/api` 仅验证编译，不能部署该占位地址。

## 验收界线与风险

- 编译成功、生成 WXML/JS/资源不代表微信真机或真实 API 联调成功。
- 当前 uni 官方发行版依赖树有 npm audit 安全警告，包括 Vue/Vite 与传递依赖；禁止以此工具链直接宣称生产安全。不要执行 `npm audit fix --force`，其建议包含降级到旧 uni 版本，可能破坏 Vue3。
- 后续需逐项评估告警可达性、采用经过兼容验证的安全补丁/上游版本，再完成生产安全验收；本轮默认仅本地回环开发服务。
- T144 保洁列表是共享团队任务，没有专属派单；可选照片及生产保洁账号创建仍待开发。
- 主工作区未提交的主题系统与 main.js/pages.json/package.json 可能重叠，合并前人工整合，不覆盖。
