# T166: 批量抄表与录入工作台

## 1. 任务背景
在多房源运营场景中，月末或月初管家需要集中记录全楼栋的水电表底数。以往逐间房打开弹窗、逐个录入的方式效率低下，且缺乏读数激增/倒流即时比对与预付余额校验。

## 2. 目标与范围
- **后端**：
  - 提供 `GET /meters/batch-sheet`：按楼栋、房间、表计类型拉取待抄底数底册，自动带出上次抄表读数与日期。
  - 提供 `POST /meters/batch`：支持多行读数批量原子提交，行级错误隔离与校验。
- **前端工作台**：
  - 类 Excel 批量工作台 (`BatchReadingDialog.vue`)，支持快捷键 Tab/Enter 单元格导航。
  - 实时用量与金额预估（阶梯单价换算）。
  - 智能告警：读数倒流（当前 < 上期）、用量激增（> 300% 环比或用量巨大）标红提醒。
  - 预付余额实时校验与扣费联动预警。

## 3. 验收标准
- [x] 后端 `getBatchSheet` 和 `createBatchReadings` 接口单元测试覆盖率 $\ge 90\%$，单元测试通过。
- [x] 前端录入工作台支持批量提交、实时差额计算、快捷键导航。
- [x] 成功量化：单个楼栋（如 20 间房）批量录入时间从 10 分钟缩减至 1 分钟以内。
