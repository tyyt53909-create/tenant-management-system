# T307 DATA-01：每日房态历史快照（本地切片）

生产化路线图 T307，与旧小程序任务编号 T307 无关。基线 `feature/t306-mqtt-local@6fb1ee9`；开发分支 `feature/t307-room-snapshot`。现有 dashboard 不重做，不含财务快照。FIN-09、FIN-10、OPS-05 在路线图标为 completed，不代表此切片或生产环境已验收；T275 证据明确原有摘要不是历史快照。

实现：管理员手动按楼栋捕获当天；PostgreSQL 单条语句统计同一视图的全部四种房态，唯一键保证并发及重试不覆盖。业务日由 BusinessClock 从捕获时间得到；记录捕获时间，缺日为 null，空楼栋是已捕获的零。无回填、覆盖或自动清理。禁止租客、保洁及非 ADMIN；与现有管理摘要权限一致。数据库 migration 仅为 expand 草稿，尚未用于真实数据库。

仪表板提供按楼栋及日期只读查询，未擷取显示缺日，空楼显示已捕获的零；切换条件或返回丢弃旧结果，不自动捕获。统计跨业务日时事务回滚并返回 409，重试才会按新业务日捕获。正式 scheduler 尚未接入或启用，未来捕获时刻需用户选择；未验证生产环境、真实数据或性能。T306 仅完成本地模拟，真实设备、TLS、ACL 和 broker 重启持久化仍待验证。
