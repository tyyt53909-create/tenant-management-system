## 技术注意事项

### 1. Element Plus主题覆盖优先级

Element Plus使用CSS变量，需要在正确的层级覆盖：
```css
/* ❌ 无效 */
.el-button--primary {
  background-color: #535b43;
}

/* ✅ 有效 */
:root {
  --el-color-primary: #535b43;
}
```

### 2. 深色模式适配

如果需要支持深色模式：
```css
@media (prefers-color-scheme: dark) {
  :root {
    --primary: #8a9476; /* 浅橄榄绿 */
    --bg-page: #2a2823;
    --bg-card: #353229;
    /* ... */
  }
}
```

### 3. TypeScript类型

为主题配置添加类型定义：
```typescript
// types/theme.d.ts
export interface QijuTheme {
  colors: {
    primary: string
    success: string
    warning: string
    error: string
    info: string
  }
  backgrounds: {
    page: string
    card: string
    section: string
  }
  // ...
}
```

### 4. 性能优化

- 使用CSS变量减少重复代码
- 避免深层嵌套选择器
- 使用transform做动画（GPU加速）
- 按需导入Element Plus组件

## 风险与挑战

### 风险1：Element Plus主题覆盖复杂
**影响**：部分组件样式可能无法完全覆盖  
**解决**：使用 `!important` 或深度选择器 `:deep()`

### 风险2：与现有业务代码冲突
**影响**：已有的行内样式可能覆盖主题  
**解决**：逐步迁移，标记需要重构的代码

### 风险3：图表库主题不一致
**影响**：ECharts等第三方库颜色不匹配  
**解决**：创建统一的图表主题配置
