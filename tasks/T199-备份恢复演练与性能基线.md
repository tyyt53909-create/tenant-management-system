# T199: 备份恢复演练与性能基线（OPT-26）

依据优化计划 OPT-26。分支从 `feature/T198-prod-deploy` 拉出。

## 目标

1. **备份与恢复灾难演练**：
   - 依据 `docs/12-部署与运维.md` §3 执行完整的生产级数据备份（`pg_dump -Fc` 自定义格式）。
   - 创建隔离的灾备验证库 `tenant_system_restore` 并执行全量恢复（`pg_restore`）。
   - 验证迁移状态与 8 大核心业务表（users, tenants, contracts, bills, payment_records, late_fees, rooms, buildings）数据 100% 完好与精确一致。
   - 实测 RTO（恢复时间目标）与 RPO（恢复点目标），将结果写入 `docs/12-部署与运维.md` §3.4。
2. **100 并发性能基线验证**：
   - 依据架构设计文档 §10.2 性能验收标准（100 并发场景下 P95 < 300ms，错误率 < 0.1%）。
   - 编写压测脚本 `scripts/perf-baseline.k6.js`，并在 `backend/package.json` 提供 `npm run test:perf` 脚本。
   - 覆盖核心接口：登录认证、账单列表、统计看板、批量抄表底册。
   - 调优数据库连接池与线程池，实测 100 并发活跃用户下的响应延迟与稳定性。

- [x] 恢复演练实际执行过，RPO ≤ 24 小时、RTO ≤ 1 小时（实测 RTO 2.4s），有完整记录写入 docs/12
