# T185: 结构化日志与健康检查（OPT-12）

依据优化计划 OPT-12。分支从 `feature/T184-error-codes` 拉出。

## 行为

- 每条访问日志是 JSON，包含 `requestId`、`userId`、`responseTime` 和状态码。
- `authorization`、`password`、`code` 写成 `[Redacted]`。
- `GET /api/health` 只表示进程存活，固定 200。
- `GET /api/health/ready` 检查数据库、Redis 和上传目录。任一失败返回 503。
- 两个健康检查接口不计入限流。

## 为什么没用 nestjs-pino

`nestjs-pino` 5 要求 Node >= 22.12。仓库 CI 仍是 Node 20。这里直接使用 `pino` 9 和 `pino-http` 10，脱敏字段和访问日志字段与计划一致。

## 验收

- [x] 请求日志含 requestId、userId、耗时、状态码
- [x] 访问日志里搜不到密码、token、验证码
- [x] 数据库检查失败时 `/health/ready` 为 503，`/health` 仍为 200
