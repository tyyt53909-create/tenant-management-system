### 主题切换逻辑

当前主题切换由 `miniprogram/utils/theme.js` 管理：
1. 用户在 `pages/theme/theme.vue` 选择主题
2. 调用 `applyTheme(themeName)` 应用主题
3. CSS变量注入到 `page` 根元素
4. 主题名称存储到 `uni.setStorageSync('theme', themeName)`

新增栖居主题后，无需修改切换逻辑，只需：
1. 在 `tokens.js` 中定义 `qijuTheme`
2. 导出到 `themes` 对象
3. 添加到 `themeList` 数组

### 字体字重兼容性

栖居版使用非标准字重（550、650、720）：
- iOS Safari：完全支持
- Android WebView：部分支持，会回退到最接近的标准字重
- 微信小程序：取决于系统WebView版本

**降级方案**：
```javascript
// 在 tokens.js 中添加注释
fontWeightRegular: 550,  // iOS 550，Android fallback to 500
fontWeightMedium: 650,   // iOS 650，Android fallback to 600
fontWeightBold: 720,     // iOS 720，Android fallback to 700
```

实际显示效果略有差异，但不影响整体视觉层次。

## 风险与注意事项

1. **颜色对比度**：米白背景 + 灰色文字可能对比度不足
   - 解决：适当加深文字颜色，确保符合 WCAG AA 标准
   
2. **字体字重**：非标准字重在部分安卓设备显示异常
   - 解决：提供降级方案，接受轻微视觉差异

3. **阴影性能**：大阴影模糊半径可能影响低端机性能
   - 解决：在关怀版主题中禁用阴影，或提供"减少动效"选项

4. **主题数量**：4个主题可能让用户选择困难
   - 建议：保持"标准版"为默认，其他3个按需选择
