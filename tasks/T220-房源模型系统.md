# T220: 房源模型系统

## 背景

现有 `/rooms` 以表格呈现房源，管理者需要逐行读取「房态 + 清洁状态」才能判断一栋楼的实际占用情况。T220 新增一个只读的空间视图，把楼栋、楼层与房间映射成 2D 剖面和 3D 等轴模型，优先解决：

- 哪些房间已出租、已预订、可出租、待清洁、清洁中、维修中；
- 同一楼层待清洁房间是否集中；
- 从空间视图直接打开现有房源详情与操作。

本任务只做 ADMIN 的第一版数据驱动模型，不新增数据库迁移。真实平面图坐标、平面图编辑器、3D 外部模型导入、CLEANER/TENANT 投影留给后续任务。

## 范围

- 新路由 `/space`，楼栋选择器。
- `SpaceModel` 纯函数适配器：
  - `Room.status + cleanStatus` → 六种显示状态；
  - 按楼层分组、房号自然排序；
  - 自动生成每层房间网格坐标；
  - 汇总可租、待清洁、清洁中、维修、已租数量。
- 2D SVG 楼栋剖面：楼层行、房间格、状态图例、hover/选中。
- 3D Three.js 等轴模型：楼层板、房间体块、六态颜色、旋转/缩放/重置、楼层隔离。
- 点击房间打开现有 `PropertyDetailPanel`。
- 在 `/buildings` 与侧栏加入入口。
- 不改变现有房态状态机，不写入任何房源数据。

## 验收标准

| # | 标准 | 验证 |
|---|---|---|
| 1 | `VACANT + CLEAN` 显示为「可出租」，`VACANT + PENDING_CLEAN` 显示为「待清洁」，两者不混淆 | `spaceModel.spec.ts` |
| 2 | 878px 视口下页面无横向滚动，2D/3D 均可切换 | Playwright 实测 |
| 3 | 3D 模型按楼层堆叠，房间颜色与六态图例一致，可旋转/缩放/重置 | 浏览器实测 |
| 4 | 点击 2D 或 3D 房间可打开 `PropertyDetailPanel` | Playwright 实测 |
| 5 | 楼层隔离后只剩目标楼层；恢复后完整显示 | 浏览器实测 |
| 6 | `npm run build` / `npm run lint` / `npm test` 全部通过 | CI 本地命令 |
| 7 | 无后端 schema 变更、无新增数据库迁移 | `git diff` 检查 |
