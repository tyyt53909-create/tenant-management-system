# T265：财务资料禁止硬删除（FIN-06）

## 背景

ISS-13：账单、退租结算单、预付账户等财务资料仍可被 `DELETE` 硬删除；关联数据存在时 Prisma `P2003` 会被映射为 500。财务记录一旦删除，流水、审计与对账无法复原。

FIN-06 要求：**财务资料只能作废/冲正，不得硬删除；外键冲突返回 409 而不是 500。**

## 范围

### 1. 禁止硬删除

- `DELETE /bills/:id`：账单是财务凭证，一律 409；改用 `PATCH /bills/:id {status:'CANCELLED'}` 作废。
- `DELETE /checkout/:id`：退租结算单一律 409；改用 `PATCH /checkout/:id {status:'CANCELLED'}` 取消。
- `DELETE /contracts/:id`：已有账单或退租记录时 409，不删除；无财务关联的合同仍允许删除。
- `DELETE /prepay-accounts/:id`：
  - 有流水或余额 ≠ 0 → 409；
  - 无流水且余额为 0 → 允许删除（不构成财务历史）。

### 2. 外键冲突统一映射

- `all-exceptions.filter` 新增 `P2003` → **409** `COMMON_CONFLICT`，消息「存在关联数据，不能删除或修改」。
- 不再把外键冲突落到 500。

### 3. 测试

- 单元：账单/退租单删除 409、合同有无财务关联、预付账户有/无流水、P2003 过滤。
- 集成（真实 DB）：账单 DELETE 409 且记录仍存在；有账单的合同 DELETE 409。

## 非目标

- 前端删除按钮的 UI 改造（后端返回 409，文案由现有提示展示；FE-01 统一）。
- 账单作废后的冲正（收款冲正已在 T264）。
- 审计日志记录删除尝试（SEC-06）。
