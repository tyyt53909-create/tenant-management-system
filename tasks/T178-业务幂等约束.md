# T178: 关键业务唯一约束（OPT-05）

依据优化计划 OPT-05。本分支从 `main` 拉出。`PaymentRecord` 已有 `(billId, transactionNumber)` 唯一索引，保持不动。

## 行为

- 租金账单写入 `dedupKey = RENT:{contractId}:{period}`。同一合同同一账期并发创建时，后到的请求返回已有账单，`alreadyExists: true`，不返回 500。
- 水电和其他账单的 `dedupKey` 为空，同一账期可以有多笔。
- 系统通知写入确定性 `dedupKey`。同一键再次创建时返回已有通知。没有关联对象的人工通知不设置键，允许重复。
- `backend/scripts/check-duplicate-business-keys.ts` 只读检查。有重复就列出并退出，不删除数据。
