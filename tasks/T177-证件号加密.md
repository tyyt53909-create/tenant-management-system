# T177: 证件号字段级加密（OPT-04）

依据优化计划 OPT-04。本分支从 `main` 拉出。

## 行为

- `CryptoService` 使用 AES-256-GCM。密钥来自 `FIELD_ENCRYPTION_KEY`。密文格式 `v1:<iv>:<tag>:<data>`。
- `tenant_registrations.idNumberHash` 保存规范化证件号的 HMAC，用于精确查重。
- 租客列表和详情只增加 `idNumberMasked`。不返回密文或明文。
- `GET /api/tenants/:id/id-number` 仅管理员可用。每次查看写 `VIEW_ID_NUMBER`，审计内容不含证件号。
- `backend/scripts/encrypt-id-numbers.ts` 可重复执行。重复证件号会停止且不写入。`--rollback` 解回明文。

## 验收

- [x] 加密结果不包含明文证件号
- [x] 列表和详情响应只有脱敏值
- [x] 查看明文产生 `VIEW_ID_NUMBER`，且 changes 不含证件号
- [x] 迁移计划对已加密行不再改写，并有回滚说明

## 迁移

```bash
cd backend && npx prisma migrate deploy
cd backend && FIELD_ENCRYPTION_KEY='...' npx tsx scripts/encrypt-id-numbers.ts
```
