# T296：预付线上充值、自动扣费与低余额提醒（PAY-04）

## 背景与目标

根据生产化路线图（docs/19 里程碑 M3）任务规划，在完成微信支付 JSAPI 收款（PAY-01 / T293）、微信退款与对账（PAY-02 / T294）、电子收款收据（PAY-03 / T295）与租客自助中心（LSE-05 / T297）的基础上，建设预付账户全链路自动化与资金闭环能力：

1. **预付线上充值（微信支付 JSAPI 充值预付账户）**：
   - 暴露 `POST /api/prepay-accounts/my/recharge/wechat-jsapi` 与 `POST /api/prepay-accounts/:id/recharge/wechat-jsapi`：
     - 支持租客端直接针对本人的预付账户发起在线充值；
     - 校验充值金额（单位：分，金额必须大于 0），提取租客 openid，通过 `PaymentProvider` 生成微信预支付订单并返回调起支付签名参数；
     - 商户单号以 `PREPAY_` 为前缀，在回调载荷中记录预付账户与租客关联信息。
   - 微信支付回调处理扩展（`WechatPaymentService.handleNotify`）：
     - 识别充值订单，事务内调用预付账户增加余额（`PrepayAccount.balanceCache += amount`）；
     - 生成预付交易流水（`PrepayTransaction`，类型为 `RECHARGE`，操作人记录为 `SYSTEM_WECHAT_PAY`）；
     - 防重复入账：全局唯一流水与幂等键保证多次回调安全幂等；
     - 同步生成电子收款收据记录（`PaymentReceipt`），确保财务台账与防伪验真连续合规。
   - 微信支付查单兜底：
     - 暴露 `POST /api/prepay-accounts/my/recharge/wechat-query`，支持前端支付完成后主动查单补入账。
2. **账单预付余额抵扣（Auto Deduct）**：
   - 暴露 `POST /api/bills/:id/pay/prepay`：
     - 允许租客或管理员使用预付账户可用余额直接抵扣缴纳未缴账单（水电账单、租金等）；
     - 在数据库事务内原子性扣减预付余额（`balanceCache` 条件更新防透支），生成 `PrepayTransaction` 扣费流水；
     - 驱动 `BillPaymentService` 记录账单收款并自动结清/核销账单，生成收据与审计日志。
3. **低余额多渠道智能预警（WX-02 / FIN-11 联动）**：
   - 当预付账户发生扣减后，如果可用余额低于预警阈值（`balanceCache < lowBalanceThreshold`）：
     - 实时触发 `NotificationDispatcher`，通过微信小程序订阅消息通道（`wechat`）下发低余额预警；
     - 记录每日防骚扰频控（`lastNotifiedAt`），避免同一天内重复向同一租客频繁轰炸；
     - 租客无微信订阅额度或未绑定时优雅回退为站内信/短信通知。
4. **小程序与契约交付**：
   - 小程序端 `miniprogram/api/prepay.js` 导出预付充值、查单与预付抵扣 API；
   - 更新 OpenAPI 规范并同步前端类型契约。
5. **真实数据库集成测试保障**：
   - 编写 `backend/test/integration/prepay-recharge.int-spec.ts`，覆盖越权校验、JSAPI 充值下单、回调幂等充值、账单预付抵扣、收据生成及低余额提醒全流程。

## 验收标准

- [x] 微信回调通知能正确解析预付充值并原子入账，幂等防御重复回调，并联动生成合规收款收据。

- [x] 余额低于阈值时触发微信订阅消息与通知提醒，具备日级频控。
