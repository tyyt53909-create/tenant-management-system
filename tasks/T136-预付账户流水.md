# T136: 预付账户充值/扣费/退款/调整（流水 + 余额联动）

## 背景

`PrepayAccount` / `PrepayTransaction` 表已建但流水零接口：余额只能靠直接改库；「水电预付」这笔钱无法充值、无法扣费、无法对账。本任务补上完整流水能力（规则依 `docs/02-数据模型.md` §2.11–2.12）。

---

## 任务范围

### 后端（prepay 模块扩展）

1. `POST /api/prepay-accounts/:id/transactions` — 登记流水（仅 ADMIN）
   - **方向规则**（amount 输入恒为正，方向由类型决定）：
     - `RECHARGE` → `+amount`；`DEDUCTION` / `REFUND` → `-amount`
     - `ADJUSTMENT` → 按 amount 符号（可正可负，不可为 0，管理员手动修正）
   - **透支政策**：`DEDUCTION` / `REFUND` 余额不足 → 400；`ADJUSTMENT` 不做余额校验
   - **并发安全**：余额用原子 `increment/decrement`；扣减走条件更新（`balanceCache >= 扣减额`）防并发透支
   - 事务内：更新 `balanceCache` + 写流水（`balanceAfter` = 操作后余额）
2. `GET /api/prepay-accounts/:id/transactions` — 账户流水分页（仅 ADMIN，时间倒序）
3. `findAll` 增强：批量补充 `roomNumber`（PrepayAccount 无 room 关系，服务层 join）
4. `CreatePrepayTransactionDto` + `QueryPrepayTransactionsDto`

### 前端（新增「预付账户」管理页）

5. 新页面 `views/prepay/index.vue`：账户列表（租客/房号/余额/低余额标红/阈值）
   - 新增账户、编辑阈值、删除
   - 「充值/扣费」对话框（类型/金额/说明，按类型限方向）
   - 「流水」对话框（±金额着色、操作后余额、分页）
6. 路由 `/prepay` + 侧边栏菜单「预付账户」（Wallet 图标）
7. `api/prepay.ts` 封装

### 测试

8. `prepay.service.spec.ts`（模块此前零测试）：10 例
   - 充值增加/扣费条件更新/余额不足 400（不写流水）/退款=出账/调整负数不校验/调整 0 拒绝/充值负数拒绝/账户不存在 404/流水分页倒序
9. `dto-validation.spec.ts` 6 例（含全局 ValidationPipe 复刻）
