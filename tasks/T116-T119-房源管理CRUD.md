## 业务规则

### 1. 房号唯一性

- 同一楼栋下的房号必须唯一
- 创建时检查：`buildingId + roomNumber`
- 更新时检查：排除自身

### 2. 房态管理

```typescript
enum RoomStatus {
  VACANT = 'VACANT',           // 空闲
  OCCUPIED = 'OCCUPIED',       // 已租
  MAINTENANCE = 'MAINTENANCE', // 维修中
  RESERVED = 'RESERVED'        // 已预订
}
```

**状态转换规则**：
- VACANT → RESERVED（预订）
- RESERVED → OCCUPIED（签约入住）
- OCCUPIED → VACANT（退租）
- 任何状态 → MAINTENANCE（报修）
- MAINTENANCE → VACANT（维修完成）

### 3. 软删除

- 删除时设置 `isDeleted = true`
- 查询时自动过滤 `isDeleted = true` 的记录
- 管理员可以看到已删除记录（可选）

### 4. 楼栋验证

- 创建房源时验证 buildingId 是否存在
- 不存在则返回 400 Bad Request
