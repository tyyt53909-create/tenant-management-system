## 详细实现步骤

### 步骤1：创建 NestJS 项目

```bash
# 安装 NestJS CLI（如未安装）
npm i -g @nestjs/cli

# 创建项目
nest new backend --package-manager npm

# 进入项目目录
cd backend
```

### 步骤2：安装核心依赖

```bash
# Prisma
npm install prisma @prisma/client

# 配置管理
npm install @nestjs/config

# 验证
npm install class-validator class-transformer

# JWT
npm install @nestjs/jwt @nestjs/passport passport passport-jwt
npm install -D @types/passport-jwt

# Bcrypt
npm install bcrypt
npm install -D @types/bcrypt

# 其他
npm install @nestjs/throttler
```

### 步骤3：配置 TypeScript 严格模式

编辑 `tsconfig.json`：

```json
{
  "compilerOptions": {
    "module": "commonjs",
    "declaration": true,
    "removeComments": true,
    "emitDecoratorMetadata": true,
    "experimentalDecorators": true,
    "allowSyntheticDefaultImports": true,
    "target": "ES2021",
    "sourceMap": true,
    "outDir": "./dist",
    "baseUrl": "./",
    "incremental": true,
    "skipLibCheck": true,
    "strict": true,
    "strictNullChecks": true,
    "noImplicitAny": true,
    "strictBindCallApply": true,
    "forceConsistentCasingInFileNames": true,
    "noFallthroughCasesInSwitch": true
  }
}
```

### 步骤4：初始化 Prisma

```bash
# 初始化 Prisma
npx prisma init

# 这会创建:
# - prisma/schema.prisma
# - .env
```

编辑 `prisma/schema.prisma`：

```prisma
generator client {
  provider = "prisma-client-js"
}

datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}

// 表定义将在 T101 任务中添加
```

### 步骤5：配置环境变量

创建 `.env.example`：

```env
# Database
DATABASE_URL="postgresql://user:password@localhost:5432/tenant_system?schema=public"

# Application
NODE_ENV=development
PORT=3000

# JWT
JWT_SECRET=your-jwt-secret-change-this-in-production
JWT_EXPIRES_IN=7d
REFRESH_TOKEN_EXPIRES_IN=30d

# File Upload
OSS_ACCESS_KEY_ID=your-oss-key
OSS_ACCESS_KEY_SECRET=your-oss-secret
OSS_BUCKET=tenant-system
OSS_REGION=oss-cn-hangzhou

# Encryption
ENCRYPTION_KEY=your-32-byte-encryption-key-change-this

# Building
DEFAULT_BUILDING_ID=building-001
```

创建 `.env`（复制 `.env.example`，添加到 `.gitignore`）

### 步骤6：创建配置模块

`src/config/app.config.ts`：

```typescript
import { registerAs } from '@nestjs/config';

export default registerAs('app', () => ({
  nodeEnv: process.env.NODE_ENV || 'development',
  port: parseInt(process.env.PORT, 10) || 3000,
  defaultBuildingId: process.env.DEFAULT_BUILDING_ID || 'building-001',
}));
```

`src/config/database.config.ts`：

```typescript
import { registerAs } from '@nestjs/config';

export default registerAs('database', () => ({
  url: process.env.DATABASE_URL,
}));
```

### 步骤7：更新 app.module.ts

```typescript
import { Module } from '@nestjs/common';
import { ConfigModule } from '@nestjs/config';
import { AppController } from './app.controller';
import { AppService } from './app.service';
import appConfig from './config/app.config';
import databaseConfig from './config/database.config';

@Module({
  imports: [
    ConfigModule.forRoot({
      isGlobal: true,
      load: [appConfig, databaseConfig],
      envFilePath: '.env',
    }),
  ],
  controllers: [AppController],
  providers: [AppService],
})
export class AppModule {}
```

### 步骤11：创建 README.md

```markdown
# 租客管理系统 - 后端

## 技术栈

- NestJS 10.x
- TypeScript 5.x
- Prisma 5.x
- PostgreSQL 16

## 快速开始

### 安装依赖

\`\`\`bash
npm install
\`\`\`

### 配置环境变量

复制 `.env.example` 到 `.env`，并修改配置：

\`\`\`bash
cp .env.example .env
\`\`\`

### 启动数据库（Docker）

\`\`\`bash
# 见根目录的 docker-compose.yml
docker-compose up -d postgres
\`\`\`

### 运行数据库迁移

\`\`\`bash
npm run prisma:migrate
\`\`\`

### 启动开发服务器

\`\`\`bash
npm run start:dev
\`\`\`

访问: http://localhost:3000

## 开发规范

### 代码风格

- 使用 ESLint 和 Prettier
- 提交前运行 `npm run lint` 和 `npm run format`

### 模块结构

每个业务模块包含：
- `*.module.ts` - 模块定义
- `*.controller.ts` - 控制器
- `*.service.ts` - 业务逻辑
- `*.dto.ts` - 数据传输对象
- `*.entity.ts` - 实体（可选，使用 Prisma）
- `*.spec.ts` - 单元测试

### 命名规范

- 文件名：小写，短横线分隔（kebab-case）
- 类名：大驼峰（PascalCase）
- 变量/函数：小驼峰（camelCase）
- 常量：大写下划线（UPPER_SNAKE_CASE）

## 测试

\`\`\`bash
# 单元测试
npm run test

# 测试覆盖率
npm run test:cov

# E2E 测试
npm run test:e2e
\`\`\`

## Prisma 命令

\`\`\`bash
# 生成 Prisma Client
npm run prisma:generate

# 创建迁移
npm run prisma:migrate

# 查看数据库
npm run prisma:studio

# 运行种子数据
npm run prisma:seed
\`\`\`
```

## 风险与注意事项

### 风险
1. **依赖版本冲突**: NestJS 和 Prisma 版本需要兼容
2. **环境变量泄露**: 确保 `.env` 已加入 `.gitignore`

### 注意事项
1. 使用 npm（不要混用 yarn 或 pnpm）
2. Node.js 版本需要 20.x
3. 所有密钥使用占位符，真实密钥通过环境变量注入
4. TypeScript 严格模式已启用，需要注意类型安全
