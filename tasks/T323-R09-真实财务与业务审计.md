# T323：真实财务与业务审计日志（R09 / SEC-06）

真实财务与关键业务变更随数据库事务同生共死写入 `AuditLog`。

- 审计事件包含真实前后值对比（`before`/`after`）、业务原因（`reason`）及上下文快照。
- 在 `AuditLogService.recordEvent` 及拦截器中引入深度递归脱敏器 `sanitizeAuditValue`，针对密码、Token、证件、手机等敏感信息统一替换为 `[REDACTED]`，并支持循环引用检测。
- 审计记录与收款（`BillPaymentService.addPayment`）、作废冲正（`BillPaymentService.voidPayment`）、押金退款/扣除/转移（`DepositsService`）、退租结清（`CheckoutService.update`）、受邀身份认领（`AuthService.register`）处于同一数据库事务（`tx`）；若必要审计写入失败，业务事务一同回滚，杜绝假成功。
- 在真实 PostgreSQL 环境下通过集成测试验证端到端入库与前后值记录。
