# T180: 启动时环境变量校验（OPT-07）

依据优化计划 OPT-07。本分支从 `main` 拉出。

## 行为

- `ConfigModule` 使用 `validateEnvironment`。
- `NODE_ENV=production` 时，缺少 `DATABASE_URL` 或 `JWT_SECRET`、以及 `JWT_SECRET` 短于 32 或仍是示例值，抛错并写明变量名。Nest 启动失败，进程非 0 退出。
- 开发模式缺少 SMTP、OSS、Redis、Google、上传目录等可选项只打印警告。
- `.env.example` 补上 `CLEANER_EMAIL`、`CLEANER_PASSWORD`、`UPLOAD_DIR`、`SMTP_*`、`MQTT_BROKER_URL`。`GOOGLE_CLIENT_ID` 原来就有。

## 验收

- [x] 生产缺少 `DATABASE_URL` 或 `JWT_SECRET` 时日志包含变量名，进程退出码非 0
- [x] 开发模式缺少可选项不阻止校验通过
- [x] `.env.example` 覆盖后端代码读取的环境变量名
