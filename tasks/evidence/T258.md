## 3. 变更要点

| 位置 | 之前 | 之后 |
|---|---|---|
| `JwtStrategy` secret | `get(...) || 'fallback-secret'` | `getOrThrow('jwt.secret')` |
| `JwtStrategy` 算法 | 未限制 | `algorithms: ['HS256']` |
| `JwtStrategy` 查询 | `user.findUnique` + TENANT 再查 `tenant.findUnique` | 单次 `user.findUnique` + `tenant: { select: { id } }` |
| `JwtAuthService` | 签发/校验未声明算法 | 全部显式 `HS256` |
| `revokeRefreshToken` | 无效 token 抛 401 | 幂等返回；存储异常仍抛出 |
| `jwt.config` | 过期时间原样透传 | 启动校验「正整数 + 单位」 |
| Refresh Cookie | 固定 7 天 | 与 `JWT_REFRESH_EXPIRY` 对齐 |
