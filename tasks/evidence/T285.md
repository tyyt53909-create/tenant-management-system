## 3. 关键行为

1. **竞态识别**：`{ code: 'AUTH_REFRESH_ROTATING', message: '任意文案' }` → 重试一次；普通 401（`AUTH_TOKEN_INVALID`）不重试直接登出。
2. **文案优先级**：`COMMON_VALIDATION_ERROR` + `details: ['邮箱不能为空', ...]` → 展示字段级信息，而非「请求参数验证失败」。
3. **不展示实现细节**：`COMMON_INTERNAL_ERROR` 的 `message: 'SELECT password FROM users'` 不会出现在 UI。
4. **去重**：请求层弹过后，页面 `catch` 再调 `notifyApiError` 静默返回。
5. **取消**：`ERR_CANCELED` 不弹提示，避免切换页面时闪现错误。
