# T293 验收证据（PAY-01 微信支付 JSAPI 收款）

> 分支：`feature/T293-wechat-pay`
> 基线：`develop` @ `bb2b518`
> 日期：2026-10-25

## 1. 变更摘要

| 模块 | 变更项 |
|---|---|
| 支付提供商 | 扩展 `PaymentProvider` 契约，实现 `WechatPaymentProvider`（API v3、RSA、AES-GCM）与 `MockPaymentProvider` |
| JSAPI 支付调起 | `POST /api/bills/:id/pay/wechat-jsapi`：租客鉴权、未缴金额校验、返回小程序 `wx.requestPayment` 调起参数 |
| 回调通知处理 | `POST /api/payments/wechat/notify`：公开路由、验签、解密报文、悲观锁与全局唯一幂等入账 |
| 主动查单补单 | `POST /api/bills/:id/pay/wechat-query`：向微信主动查单并驱动入账 |
| 客户端与测试 | 小程序封装支付接口；单元测试、真实 PostgreSQL 集成测试与全套门禁通过 |
