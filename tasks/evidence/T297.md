# T297 验收证据（LSE-05 租客自助中心）

> 分支：`feature/T297-tenant-self-service`
> 基线：`develop` @ `999938f`
> 日期：2026-10-26

## 1. 变更摘要

| 模块 | 变更项 |
|---|---|
| 租客自助服务与数据看板 | 在 `TenantsService` 与 `TenantsController` 新增 `GET /api/tenants/me/overview`，聚合生效合同、租期倒计时、待缴账单总额、预付余额、活跃报修单与实名认证状态，未绑定邀请码租客安全降级 |
| 租客自助实名登记与状态流转 | 暴露 `GET /api/tenants/me/registration` 与 `POST /api/tenants/me/registration`；租客可自助登记证件信息并更新紧急联系方式，进入 `PENDING` 待审状态；证件号执行 AES-256 加密与 HMAC 查重哈希，记录完整审计；已审核通过（`REGISTERED`）禁止私自篡改 |
| 租客电子收据列表与导出 | 暴露 `GET /api/bills/my/receipts`，支持租客查询名下全部已出具电子收款收据；严格执行租客身份隔离与防越权保护 |
| 小程序账单详情线上直缴与收据下载 | 小程序账单详情（`bill-detail.vue`）接入微信支付 JSAPI 收银台；待缴账单可一键拉起支付；已缴账单提供官方电子收款收据展示与标准 PDF 原生下载预览能力 |
| 小程序租客自助工作台与验真工具 | 小程序个人中心（`profile.vue`）全面升级为租客自助中心，呈现 4 项核心数据与 4 大自助服务（我的收据、防伪验真、实名认证、快捷交费）；集成独立收据中心弹窗、支持扫码核验的防伪验真工具及实名登记审核弹窗 |
| 门禁与全套测试 | 补齐后端单元测试（156 文件，1491 测试全绿）、覆盖率检查（各指标全量达标）、真实 PostgreSQL 数据库集成测试（26 文件，81 测试全绿）与小程序页面/API 单元测试（140 测试全绿） |
