## 3. 关键用例

1. 有效 Access Token → join `user:u1`；Refresh token / 无 token / 验签失败 → `disconnect(true)`。
2. `emitNotification` 只向 `user:{id}` 房间发 `notification`；无 server 不抛错。
3. 前端断线回退轮询、重连停止（代码审查 + `vue-tsc`）。
