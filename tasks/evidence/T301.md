# T301 验收证据（LSE-04 到期提醒、续约意向与续约报价）

> 分支：`feature/T301-contract-renewal-reminders`
> 基线：`develop` @ `8500c38`
> 日期：2026-10-26

## 1. 变更摘要

| 模块 | 变更项 |
|---|---|
| 数据模型与迁移 | 新增 `renewal_intents`（续约意向）与 `renewal_offers`（续约报价）两张表，数据表数严格对齐至 54 张表 |
| 合同到期梯次提醒 | `SchedulerDailyJobsService` 新增 `sendExpiringContractReminders()`，支持 30天、15天、7天梯次扫描与去重提醒（带 `CONTRACT_EXPIRING` 唯一 dedupKey），自动推送站内信/微信提醒 |
| 租客续约意向填报 | 实现 `submitRenewalIntent` 与 `getRenewalIntent`，支持租客在线表达续约意愿（RENEW / NOT_RENEW / CONSIDERING）、期望租期、期望月租与备注留言 |
| 管家定制续约报价与租客确认 | 实现 `createRenewalOffer`、`findAllRenewalOffers`、`findMyRenewalOffers`、`respondRenewalOffer`；租客确认接受报价自动联动 `contractsService.renew` 生成续租合同草稿（`renewedContractId`）并绑定原合同 |
| 到期滞留（Holdover）监控 | 解决遗留缺陷 **ISS-20**，实现 `findHoldoverContracts`，精准检测合同已 EXPIRED 但房间仍 OCCUPIED、既未续签也未退租的滞留租约与逾期天数 |
| 客户端与小程序 | `miniprogram/api/contracts.js` 扩展续约意向与报价 API，168 个小程序测试全绿 |
| 质量门禁与测试 | 166 个后端单元测试文件（1625 测例全绿）、后端覆盖率（Statements 85.22%, Lines 86.26%）、31 个真实 PostgreSQL 集成测试（98 测例全绿）、OpenAPI 契约（259 路由）全绿 |
