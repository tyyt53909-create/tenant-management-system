# T303 验收证据（WRK-02 维修工单：派工、SLA、员工端、费用转嫁）

> 分支：`feature/T303-maintenance-dispatch-sla`
> 基线：`develop` @ `4565c97`
> 日期：2026-10-26

## 1. 变更摘要

| 模块 | 变更项 |
|---|---|
| 数据模型与迁移 | `MaintenanceRequest` 扩充 SLA 时限字段（`responseDueAt`, `slaDueAt`, `firstRespondedAt`, `isSlaBreached`, `slaBreachedAt`, `slaBreachType`）、维修工关联字段（`assignedMaintainerId`）与费用转嫁字段（`laborCost`, `materialCost`, `totalCost`, `tenantFault`, `faultReason`, `expenseTransferred`, `expenseBillId`, `expenseTransferredAt`）；`BillType` 扩充 `MAINTENANCE`；表数严格维持 55 张表 |
| 维修派工与全角色流转 | 实现 `POST /maintenance/:id/dispatch`，支持管理员与管家指派特定维修师傅（`MAINTAINER`），状态流转至 `ASSIGNED` 并自动记录 `assignedAt`、首响时间与系统时间线事件；管家端受负责楼栋范围隔离保护 |
| SLA 时限计算与监控告警 | 实现 `calculateMaintenanceSla` 与 `evaluateSlaStatus`：按优先级（URGENT 2h/24h, NORMAL 12h/48h, LOW 24h/72h）计算响应与解决截止时间；实现 `GET /maintenance/sla-alerts` 实时检测与标记超时工单 |
| 维修工专属端点 | 实现维修师傅专属工单查询 `GET /maintenance/assigned`、接单开工 `POST /maintenance/:id/start`（流转至 `IN_PROGRESS`）以及提报完工说明与用料成本 `POST /maintenance/:id/complete`（流转至 `PENDING_CONFIRM`） |
| 验收与过失费用转嫁 | 实现租客/管理员验收确认 `POST /maintenance/:id/confirm`（确认完成流转至 `COMPLETED` 并记录 `resolvedAt`；驳回重修退回 `IN_PROGRESS`）；实现租客过失维修费用转嫁生成租客账单 `POST /maintenance/:id/transfer-expense`（`billType: MAINTENANCE`，幂等防重复生成） |
| 质量门禁与测试 | 171 个后端测试文件（1670 测例全绿）；后端覆盖率（Statements 85.12%, Lines 86.11%）；33 个真实 PostgreSQL 集成测试（100 测例全绿，新增 `maintenance-sla-dispatch.int-spec.ts`）；OpenAPI 契约扩展至 270 条路由 |
