## 2. 实测记录

测试方式：用 `nginx:1.27-alpine` 挂载仓库内两份配置与自签证书；本机 Docker bridge 不可用，测试副本仅把 `backend:3000` 换成 `127.0.0.1:13000` 的测试上游，其余内容与仓库一致。

### 上传

```text
8MB  -> 200 application/json  {"bytes":8388608}
11MB -> 413 application/json  {"code":"PAYLOAD_TOO_LARGE","message":"请求体超过 10MB 上限"}
```

### 安全头（HTTP `/`）

```text
X-Content-Type-Options: nosniff
Referrer-Policy: strict-origin-when-cross-origin
X-Frame-Options: SAMEORIGIN
Permissions-Policy: camera=(), microphone=(), geolocation=()
Content-Security-Policy: default-src 'self'; script-src 'self' https://accounts.google.com; ...
```

`/index.html` 在 `Cache-Control: no-store` 之外重复声明同一组安全头（nginx 的 `add_header` 不继承）。HTTPS 额外返回 `Strict-Transport-Security: max-age=31536000; includeSubDomains`。

### 限流

```text
seq 1 120 | xargs -P 30 curl ... /api/ping
     64 200
     56 429
```

符合 `rate=30r/s, burst=60` 的预期。

### 配置校验

```bash
docker run --rm nginx:1.27-alpine nginx -t   # syntax is ok / test is successful
docker compose -f docker-compose.prod.yml -f docker-compose.tls.yml config
# web: 80→8080、443→8443；挂载 certs 与 tls.conf
```
