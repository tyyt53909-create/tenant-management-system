## 3. 关键用例

1. **指标文本**（单元）：counter 累积、gauge 覆盖、histogram 累积桶/sum/count、标签转义（引号/反斜杠/换行）。
2. **访问控制**（单元）：生产 + token 缺失 → 401；错误 token → 401；Bearer/query 正确 → 200；生产未配置 → 404。
3. **告警**（单元）：无 URL 不发网络请求；有 URL 带 Bearer 发送 JSON；同 dedupeKey 限频；网络错误不抛出。
4. **JobRun**（单元）：子任务 `errors` 非空 → `PARTIAL` 且 observer 收到 PARTIAL；全量失败 → `FAILED`；锁 TTL 透传。
5. **真实端点**（集成）：`/health/live` 后抓 `/metrics` 返回 200 且含 HTTP 请求指标与进程指标。
