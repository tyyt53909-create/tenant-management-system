## 3. 变更要点

| 位置 | 之前 | 之后 |
|---|---|---|
| 唯一索引 | `roomId WHERE status IN ('DRAFT','ACTIVE')` | `roomId WHERE status='ACTIVE'` |
| 续签 | 原合同 ACTIVE 时新建 DRAFT → P2002 | 201 DRAFT，旧合同保持 ACTIVE |
| 续签日期 | 未校验重叠 | 新起始日必须 > 旧到期日；默认次日 |
| 激活 | 任何未结束合同都 409 | 续签原合同可在同事务先 RENEWED 再激活 |
| 定时任务 | 直接激活所有 DRAFT | 续签 DRAFT 先 RENEWED；仍有 ACTIVE 时跳过 |
| DRAFT 续签 | 允许 | 400 |

迁移：`20261024190000_contract_active_unique`（drop 旧索引 + create 新索引），已在本地 PostgreSQL 16 执行。
