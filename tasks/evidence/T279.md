## 3. 关键用例

1. **跨实例 access token**（集成）：实例 A 登录，实例 B 用该 token 访问 `/tenants` 返回 200。
2. **跨实例 refresh**（集成）：实例 A 的 refresh token 在实例 B `/auth/refresh` 成功轮换并返回新 access token。
3. **启动约束**（单元）：生产 `MULTI_INSTANCE=true` + `STORAGE_DRIVER=local` 抛错；S3 模式通过。
4. **Redis 连接语义**：并发调用等待同一连接，不再出现「后到模块拿到 ready=false」。
