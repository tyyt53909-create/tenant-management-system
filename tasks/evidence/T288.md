## 3. 关键改造

### 3.1 消除静默降级

| 文件 | 改造前 | 改造后 |
|---|---|---|
| `bills.service.ts` | 4 个 `@Optional()` + `?? new` | 全部构造注入 |
| `bill-payment.service.ts` | `?? new OfflinePaymentProvider()` / `?? new BusinessClock(new ConfigService())` | 注入 `PAYMENT_PROVIDER` + 共享 `BusinessClock` |
| `meters.service.ts` | 8 个 `@Optional()` | 全部构造注入，`MetersModule` 唯一装配点 |
| `meter-reading/batch-usage-query/reconciliation/price.service.ts` | 各自 `new MeterPriceService` / `new BusinessClock` | 容器注入 |
| `email-otp.service.ts` | `?? new MemoryOtpStore()` | `@Inject(OTP_STORE)` 必填 |
| `auth.service.ts` | `?? new MemoryLoginAttemptStore()` / 内部 `new FederatedAuthService` | 均改为构造注入 |
| `notifications.service.ts` | `?? NotificationDispatcher.createDefault()` | 模块工厂提供 dispatcher |
| `announcements.service.ts` | `@Optional()` 通知服务 | 必填 |

### 3.2 剩余可选依赖（7 处，均注明原因）

scheduler（观测/队列开关）、notifications（WS 网关）、jwt（`REFRESH_STORE`）、
capability guard（能力服务）、simulator（anomalyRunner）。

### 3.3 RoomsService 拆分

- `room-photos.ts`：`photoKey` / `collectPhotoKeys` / `buildRoomPhotoRows` / `bindPhotoAssets`。
- `room-transitions.ts`：`ALLOWED_ROOM_TRANSITIONS` / `isTransitionAllowed` / `requiredPreconditions` /
  `assertTransitionTable` / `assertPreconditionMet`。
- service 内 `assertTransitionAllowed` 只负责「按 kind 查一次库」。
