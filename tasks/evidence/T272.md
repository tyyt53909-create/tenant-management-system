## 1. 变更摘要

| 目标 | 实现 |
|---|---|
| 状态拆分 | `Bill` 增加 `isOverdue` / `overdueDays`；`status` 只写 PENDING/PARTIAL/PAID/CANCELLED；迁移把历史 OVERDUE 回填为缴付进度 + 逾期标记 |
| 筛选 | `GET /bills?overdue=true`；`status=OVERDUE` 兼容映射；列表/导出共用筛选 |
| 滞纳金按日 | 新增 `late_fee_accruals`（billId + accrualDate 唯一）；每日任务写「累计(today) − 累计(yesterday)」，重复执行幂等 |
| 建议值 | 保留 `LateFee` 建议/确认/核销流程，每日刷新为累计应付 |
| 催缴节点 | 移除逾期检查里的即时通知，只保留 −3 / 0 / +1 / +3 / +7 节点去重提醒 |
| 收款 | PAID 清除 `isOverdue/overdueDays`；PARTIAL 保留；作废按到期日重算 |
| 指标 | 统计/管理摘要/仪表板改用 `isOverdue` 计数 |
| 前端 | 逾期行显示「逾期 N 天」；「逾期」Tab 走 `overdue=true`；类型补字段 |

## 3. 关键用例

1. **逾期不覆盖状态**（集成）：逾期账单跑两次日任务后 `status=PENDING`、`isOverdue=true`、`overdueDays>0`；`late_fee_accruals` 仍只有 1 条，金额 100 分。
2. **筛选兼容**（集成）：`overdue=true` 与 `status=OVERDUE` 都返回该账单，且返回行 `status` 不为 OVERDUE；`status=PENDING` 也能查到。
3. **收款语义**（集成）：部分收款后 `PARTIAL + isOverdue=true`；本金付清后 `PAID`，`isOverdue=false`、`overdueDays=0`。
4. **日增量**（单元）：固定日额 100；宽限期内 0；`cap=1500` 时第 1/2/3 天分别 1000/500/0。
5. **提醒去重**（单元）：逾期检查不再调用通知；提醒任务仍按节点发送。
