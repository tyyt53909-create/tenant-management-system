## 1. 变更摘要

| 模块 | 变更项 |
|---|---|
| 数据模型与迁移 | 新增 `leads` 与 `viewing_appointments` 表，`rooms` 新增 `listingPrice`, `isListed`, `availableDate` 挂牌字段；表数对齐至 47 张 |
| 房源公开呈现 | `GET /api/public/rooms` 与 `GET /api/public/rooms/:id` 仅暴露上架可租房源，带出挂牌价格（分及元）、起租日期与空间平面图联动信息 |
| 房源分享卡片 | `GET /api/public/rooms/:id/share`：提供微信小程序卡片与海报元数据标准格式 |
| 意向留资管线 | 访客免登录 `POST /api/public/leads` 提交看房意向，管理端 `GET /api/leads` 与 `PATCH /api/leads/:id` 跟进生命周期 |
| 看房预约生命周期 | 访客 `POST /api/public/appointments` 预约看房，管理端 `PATCH /api/appointments/:id/confirm` 确认排期并通知，现场带看 `complete` 填反馈，支持安全取消 |
| 小程序与客户端 | `miniprogram/api/public.js` 导出挂牌看房、分享、留资与预约 API，编写 151 个全绿测试 |
| 质量门禁与测试 | 158 个后端单元测试文件（1529 测例）、28 个真实 PostgreSQL 集成测试（90 测例）、OpenAPI 契约（222 路由）全绿通过 |
