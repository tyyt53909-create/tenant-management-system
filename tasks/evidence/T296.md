# T296 验收证据（PAY-04 预付线上充值、自动扣费与低余额提醒）

> 分支：`feature/T296-prepay-recharge-auto-deduct`
> 基线：`develop` @ `bcc2408`
> 日期：2026-10-26

## 1. 变更摘要

| 模块 | 变更项 |
|---|---|
| 预付数据模型 | 新增 `prepay_recharge_orders` 表，扩充 `PaymentMethod.PREPAY` 与 `RelatedType.ONLINE_RECHARGE/BILL_DEDUCTION`，表数对齐至 45 张 |
| JSAPI 充值下单 | `POST /api/prepay-accounts/my/recharge/wechat-jsapi` 与 `POST /api/prepay-accounts/:id/recharge/wechat-jsapi`：生成 PENDING 充值单与小程序调起支付参数 |
| 回调通知处理 | `POST /api/payments/wechat/notify`：解析预付充值订单，事务内原子增加余额、记预付流水、分配连续收据编号，多次回调保持幂等 |
| 主动查单补单 | `POST /api/prepay-accounts/my/recharge/wechat-query`：向微信主动查单并驱动自动补入账 |
| 账单预付抵扣 | `POST /api/bills/:id/pay/prepay`：租客/管理者使用预付余额抵扣账单，条件更新防透支，结转账单状态并流转押金/收据 |
| 低余额智能预警 | 扣费后检测 `balanceCache < lowBalanceThreshold`，实时触发 `NotificationDispatcher` 下发微信订阅消息通知并具备日级频控 |
| 小程序与客户端 | `miniprogram/api/prepay.js` 与 `bills.js` 导出充值、查单与预付抵扣接口并编写自动化测试 |
| 测试与发布门禁 | 156 个后端单元测试文件（1501 测例）、27 个真实 PostgreSQL 集成测试（86 测例）、小程序单测（144 测例）、OpenAPI 契约（209 条路由）全绿通过 |
