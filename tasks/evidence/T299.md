# T299 验收证据（LSE-02 合同模板、PDF、电子签约与共同承租人）

> 分支：`feature/T299-contract-template-sign-cotenants`
> 基线：`develop` @ `ecd9b55`
> 日期：2026-10-26

## 1. 变更摘要

| 模块 | 变更项 |
|---|---|
| 数据模型与迁移 | 新增 `contract_templates` 与 `contract_co_tenants` 表，`contracts` 扩展 `templateId`、`signStatus`、`signFlowId`、`signedAt`、`signDocUrl`；表数由 47 增至 49 张对齐 |
| 共同承租人 | 支持合同创建/编辑与独立追加/移除共同承租人；证件号通过 `CryptoService`（AES-256-GCM）加密存储，详情返回脱敏 `idNumberMasked` |
| 合同条款模板 | 提供 `ContractTemplatesService` 与控制器，内置默认标准租赁模板（`STANDARD_RESIDENTIAL`），支持变量占位符渲染 |
| 合同 PDF 导出 | `GET /api/contracts/:id/pdf`：零依赖纯 TypeScript PDF 1.4 生成器，输出标准房屋租赁合同并带防伪时间戳，具备租客越权隔离防护 |
| 第三方电子签约 | 抽象 `ElectronicSignProvider` 接口与 `MockElectronicSignProvider`；实现发起签约、进度查询、状态流转、签署回调并自动归档合同附件（`CONTRACT_SCAN`） |
| 小程序与客户端 | `miniprogram/api/contracts.js` 扩展详情、电子签状态、PDF 路径与默认模板 API，157 个小程序测试全绿 |
| 质量门禁与测试 | 162 个后端单元测试文件（1554 测例）、29 个真实 PostgreSQL 集成测试文件（94 测例）、OpenAPI 契约（235 路由）全绿通过 |
