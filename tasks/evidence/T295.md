## 1. 变更摘要

| 模块 | 变更项 |
|---|---|
| 收据与防伪服务 | 扩展 `BillReceiptService` 支持防伪码（HMAC）生成、单笔收款与整单收据装配、作废状态流转 |
| 公开收据验真 | 暴露 `@Public()` 路由 `GET /api/public/receipts/:receiptNumber/verify` 与 `GET /api/public/receipts/verify`，支持收据真伪与作废状态查验，执行隐私脱敏（SEC-08） |
| 收据 PDF 导出 | 实现纯 TypeScript 标准 PDF 1.4 生成引擎 `ReceiptPdfBuilder`，暴露管理端与租客端 PDF 导出端点，以及公开 PDF 下载端点，支持作废水印 |
| 测试与门禁 | 补充单元测试、覆盖率检查（全量达标，`bill-receipt.service.ts` 分支覆盖率 97.2% ≥ 90%）、OpenAPI 检查及真实 PostgreSQL 数据库集成测试（25 文件 80 测试通过） |
