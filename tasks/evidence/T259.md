## 3. 变更要点

| 位置 | 之前 | 之后 |
|---|---|---|
| OTP 生成 | `Math.floor(100000 + Math.random() * 900000)` | `crypto.randomInt(100000, 1000000)` |
| OTP 存储 | JSON 明文 `code` + `failedAttempts` 读改写 | `codeHash`（HMAC-SHA256 + 随机盐）+ 独立原子计数器 |
| OTP 比较 | 字符串 `!==` | `crypto.timingSafeEqual` |
| OTP 失败计数 | `get` → 改对象 → `set` | `INCR` + `PEXPIRE`（Redis）/ 计数 Map（内存） |
| 登录失败 | 无限制 | 5 次 / 15 分钟锁定，429；成功清零 |
| 登录枚举 | 无密码账号返回专属文案；未知账号不比对密码 | 统一 401 文案；未知账号执行 dummy bcrypt 等时比对 |
| 禁用账号 | 先判 `isActive` 再验密码（可枚举） | 先验密码，密码正确才 403 |
| bcrypt | 固定 cost 10 | `BCRYPT_ROUNDS` 默认 12（10–14），旧哈希兼容 |
| 邀请码 | `Math.random()` | `randomHex(3)` |
