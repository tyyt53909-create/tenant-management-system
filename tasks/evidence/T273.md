## 3. 结算事务

`PATCH /checkout/:id {status:'COMPLETED'}` 同一事务内：

1. 状态校验（仅 PENDING → COMPLETED）；
2. 结算等式：`totalRefund = 退款项 - 扣款项`；
3. 押金结清：`DEPOSIT_DEDUCTION + 现金退还 = 台账余额`，写 DEDUCT/REFUND，余额 0、REFUNDED；
4. 合同 ACTIVE → TERMINATED；
5. 房间 OCCUPIED → VACANT + PENDING_CLEAN；
6. 失败整体回滚；重复完成幂等。
