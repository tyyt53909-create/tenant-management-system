# T300 验收证据（LSE-03 入住/退租验房与租客退租申请）

> 分支：`feature/T300-inspection-checkout-request`
> 基线：`develop` @ `29d5015`
> 日期：2026-10-26

## 1. 变更摘要

| 模块 | 变更项 |
|---|---|
| 数据模型与迁移 | 新增 `room_inspections`、`inspection_items` 与 `checkout_requests` 表，`checkout_records` 扩展 `inspectionId`；数据表数严格对齐至 52 张表 |
| 房屋交付与交接验房 | 实现 `InspectionsService` 与控制器，支持入住（CHECK_IN）与退租（CHECK_OUT）交接单据、水电气底数快照、现场照片、物品损坏扣费估算及租客在线确认签署 |
| 租客自主退租申请 | 实现 `CheckoutRequestsService` 与端点，租客端可在合同生效期内自主发起退租申请，支持填写期望退租日、原因与收款账户，支持待审核撤回 |
| 管理员审批与退租单联动 | 管理员审批退租申请（通过/驳回），审批通过自动联动生成退租单草稿（`CheckoutRecord`），驳回记录明确原因并向租客推送站内通知 |
| 设置中心与规则联动 | `SETTING_DEFINITIONS` 引入 `leasing.defaultInspectionItems` 默认物品模板与 `leasing.minCheckoutAdvanceDays` 提前退租天数配置 |
| 客户端与小程序 | `miniprogram/api/checkout.js` 与 `miniprogram/api/inspections.js` 封装退租申请与验房 API，164 个小程序单元测试全绿 |
| 质量门禁与测试 | 165 个后端单元测试文件（1592 测例）、30 个真实 PostgreSQL 集成测试文件（97 测例）、OpenAPI 契约（249 路由）全绿通过 |
