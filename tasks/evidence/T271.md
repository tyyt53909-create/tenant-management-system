## 1. 变更摘要

| 目标 | 实现 |
|---|---|
| 登记写入 | `POST /tenants` / `PATCH /tenants/:id` 支持成对 `idType` + `idNumber`；同事务写 `TenantRegistration`；重复 hash 409 |
| 登记接口 | `GET/PUT /tenants/:id/registration`（ADMIN）；首次必须带证件号，之后可只改状态/备注 |
| 状态机 | `NOT_REGISTERED → PENDING/REGISTERED`、`PENDING → REGISTERED/REJECTED`、`REJECTED → PENDING/REGISTERED`；非法回退 409；REGISTERED 写 `registeredAt` |
| 脱敏 | 列表/详情/登记接口只返回 `idNumberMasked`；明文仅 `GET /tenants/:id/id-number` |
| 审计 | `VIEW_ID_NUMBER`（仅 tenantId）、`UPDATE_TENANT_REGISTRATION`（idType/status/changedFields，不含值/明文/密文/hash） |
| 密钥轮换 | `ENCRYPTION_KEY_PREVIOUS`（多把旧钥）+ `--rotate` 迁移（dry-run 默认，`--apply` 落库）；新数据始终当前钥 |
| 前端 | 租客表单补证件类型/号码，不再丢弃；编辑留空表示不改 |

## 3. 关键用例

1. **创建带证件号**（集成）：`POST /tenants` 返回 `idNumberMasked=4401**********1234`，响应不含明文；库内为 `v1:` 密文 + hash。
2. **查看留痕**（集成）：`GET /tenants/:id/id-number` 返回明文；`VIEW_ID_NUMBER` 审计的 `changes` 不含明文/掩码。
3. **重复登记**（集成）：同一证件号第二个租客 409；只传号码不传类型 400。
4. **状态机**（集成）：`NOT_REGISTERED → REGISTERED` 写 `registeredAt`；`REGISTERED → NOT_REGISTERED` 409；只改状态时证件号密文与 hash 不变。
5. **换钥**（单元）：旧钥密文可由 `[新钥, 旧钥]` 解密；rotate 计划用新钥重加密并重算 hash，旧钥无法解新密文。
6. **更新号码**（集成）：`PATCH /tenants/:id` 后旧号码可给新租客使用，响应仍只给脱敏值。
