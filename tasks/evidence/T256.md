## 3. 目录覆盖

- `ERROR_CATALOG`：36 个错误码，与 `docs/05-接口规范.md` §5.2 逐项一致（含状态码）。
- `ErrorCode` 由目录派生，既有 `ErrorCode.XXX` 调用点无需修改。
- `apiError()` 新入口；`codeForMessage()` 保留为迁移期兜底，显式 code 必须在目录内才生效。

## 4. 已迁移的高风险路径

| 位置 | 之前 | 之后 |
|---|---|---|
| 房态非法流转（`rooms.service`） | `BadRequestException` 400，靠消息推断 | `ROOM_NOT_AVAILABLE` 422 |
| 房态乐观锁冲突（4 处） | `ConflictException` 409，靠消息推断 | `ROOM_VERSION_CONFLICT` 409 |
| 滞纳金-账单已缴清 | `BadRequestException` 400 | `BILL_ALREADY_PAID` 422 |
| 预付余额不足 | `BadRequestException` 400 | `PREPAY_INSUFFICIENT_BALANCE` 422 |

前端按 `code` 分支（`ROOM_VERSION_CONFLICT`、`AUTH_TOKEN_*`、`COMMON_VALIDATION_ERROR`），不受状态码调整影响。
