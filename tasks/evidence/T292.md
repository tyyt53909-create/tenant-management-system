# T292 验收证据（WX-03 短信通道与短信 OTP）

> 分支：`feature/T292-sms-otp`
> 基线：`develop` @ `0a82428`
> 日期：2026-10-25

## 1. 变更摘要

| 模块 | 变更项 |
|---|---|
| 短信提供商 | 实现 `SmsProvider` 接口与 `AliyunSmsProvider`、`MockSmsProvider` |
| 短信通知渠道 | 实现 `SmsChannel` 接入 `NotificationDispatcher`，支持渠道点名 `sms` 与优雅跳过 |
| 验证码服务 | 实现 `SmsOtpService`，提供加盐 HMAC 存储、60s 冷却、5m 有效期与 5 次熔断 |
| 认证接口 | 新增 `POST /auth/send-sms-code`、`POST /auth/login-sms-code` 与 `POST /auth/bind-phone-sms` |
| 客户端与测试 | 小程序封装短信接口；补充单元测试与真实 PostgreSQL 数据库集成测试 |
