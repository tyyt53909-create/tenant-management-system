## 3. 关键用例

单元（`announcements.service.spec.ts`）：
1. `ALL_TENANTS` 忽略残留 `targetIds`；定向缺 ID / ID 不存在 → 400 且不落库；重复 ID 去重。
2. 受众解析：只取 `isActive` 且有 `userId` 的租客；BUILDING 只取 ACTIVE 合同并去重；TAGS 走 `tenant_tags`。
3. 发布：按去重键逐个投递；单用户失败不影响其他人并计入 `failed`；已归档拒绝发布。
4. 生命周期：已发布不可编辑/删除；草稿可删；归档幂等；`publish=true` 创建即发布。

集成（`announcements.int-spec.ts`，真实 PostgreSQL）：
1. 草稿 → 发布：租客通知箱各 1 条、未读 1；管理员本人不在受众内。
2. 重发幂等：两次发布后通知仍只有 1 条。
3. BUILDING 定向只达目标楼栋；不存在的楼栋 ID → 400 并列出缺失 ID。
4. TAGS 定向只达带标签租客；无匹配标签时 `recipients=0` 且无通知。
5. 已发布 PATCH/DELETE → 409；归档后通知保留。
6. CLEANER / TENANT 访问列表与创建 → 403；草稿可编辑可删除。
