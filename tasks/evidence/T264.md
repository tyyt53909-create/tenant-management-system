## 3. 变更要点

| 位置 | 之前 | 之后 |
|---|---|---|
| 行锁 | `try/catch {}` 吞掉所有错误 | 直接 `SELECT ... FOR UPDATE`，异常上抛 |
| 幂等 | 仅交易号（应用层查重） | `Idempotency-Key` 全局唯一；同键同请求返回原记录 |
| 并发重复 | P2002 可能 500 | P2002 → 409 |
| 收据号 | 无 | 数据库序列 `R{业务日}{6 位序号}` |
| 作废 | 无 | VOIDED + 负额 REVERSAL，账单/滞纳金精确回退 |
| 滞纳金回滚 | 无法还原 | `lateFeeAllocations` 精确减少 settledAmount，必要时清空 settledAt |

迁移：`20261024200000_payment_correctness`（枚举、列、唯一索引、序列、历史回填）。
