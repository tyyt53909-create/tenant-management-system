## 3. 变更要点

| 位置 | 之前 | 之后 |
|---|---|---|
| 业务日 | `new Date()` + 进程本地时区 | `BusinessClock.todayUtc()`（Asia/Shanghai → UTC 零点） |
| 月份桶 | `now.getFullYear()/getMonth()` | `clock.startOfMonth/addMonths/monthKey` |
| 季度/年度范围 | `new Date(y, m, 1)` | `clock.startOfQuarter/endOfQuarter/startOfYear/endOfYear` |
| 收据/导出文件名 | `new Date().toISOString()` | `clock.formatDate()` |
| 水电到期日 | `dueDate.setDate(+7)` | `clock.addDays(clock.todayUtc(readingTime), 7)` |
| 导入日期 | `new Date('YYYY-MM-DDT00:00:00Z')` | `parseDateOnly`（严格校验溢出） |
| 合同号/水电账单号 | `Math.random()` | `randomHex(3)`（普通账单号当时漏改，已在 T264 审查修正） |
