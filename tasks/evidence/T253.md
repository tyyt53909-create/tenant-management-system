## 3. 镜像构建与运行实测

```bash
docker build --network host -f backend/Dockerfile backend -t tenant-backend:t253
# Successfully tagged tenant-backend:t253
```

> 本机 Docker bridge 网络故障，构建与运行使用 `--network host`；与镜像内容无关。

镜像内：

```text
node -v        -> v24.22.1
id             -> uid=1001(app) gid=101(app)
GET /api/health/live   -> 200
GET /api/health/ready  -> 200
```

加固参数（等价于 `docker-compose.prod.yml` 中 backend 服务）：

```bash
docker run --init --read-only --tmpfs /tmp --cap-drop ALL \
  --security-opt no-new-privileges -v t253-uploads:/app/uploads ...
```

停机实测：

```text
stop_ms=72
[Shutdown] 收到 SIGTERM，开始优雅关闭（最多 25000ms）
[RedisService] Redis 连接已关闭
exit=143   # Nest 在 close() 完成后按约定重新抛出信号
```

数据库迁移在镜像内执行成功（`prisma migrate deploy` → No pending migrations）。
