# T294 验收证据（PAY-02 微信支付退款、日终对账与差异处理）

> 分支：`feature/T294-wechat-refund-reconciliation`
> 基线：`develop` @ `c8d2f18`
> 日期：2026-10-27

## 1. 变更摘要

| 模块 | 变更项 |
|---|---|
| 支付提供商契约 | `PaymentProvider` 扩展退款申请 `createRefund`、退款查询 `queryRefund`、退款回调解密 `verifyAndParseRefundNotify`、对账单下载 `downloadTradeBill` |
| 微信提供商实现 | `WechatPaymentProvider` 实现微信 API v3 国内退款 (`/v3/refund/domestic/refunds`) 请求签名构造与 AES-GCM 通知解密，支持微信账单 CSV 解析 |
| 模拟通道实现 | `MockPaymentProvider` 完整模拟退款存储、状态查询、退款成功/异常通知解析与对账流水下载（支持注入模拟单边账） |
| 退款业务端点 | `POST /api/bills/:id/payments/:paymentId/refund`（仅管理员 `@Roles('ADMIN')`）：校验微信渠道与可退余额，退款成功后账单财务冲正回滚并重算实缴额与状态 |
| 退款通知回调 | `POST /api/payments/wechat/refund-notify`（公开路由 `@Public()`）：验签并解密退款状态报文，确认退款结果 |
| 日终对账端点 | `POST /api/bills/reconciliation/wechat`（仅管理员 `@Roles('ADMIN')`）：拉取官方微信账单与本地数据进行比对，准确识别平账、微信单边账、本地单边账与金额不符，支持 `autoSyncMissing` 自动补账 |
| 客户端与测试 | 小程序封装退款与对账 API；补齐对应单测与全局门禁验证 |
