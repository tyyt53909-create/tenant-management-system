# T320：押金冲正与退租闭环（R07 / R08）

押金冲正余额不足时拒绝，不再把余额夹成 0。退款、扣款、转移支持幂等键，转移前锁定台账并核对续签关系和租客。退租房间必须来自合同。已完成或已取消的单据不能改财务字段。到期合同可以完成退租。没有押金台账时不能自动当成零押金完成。续签后的新合同仍占用房间时，旧退租不释放房间。

`plan_ref` 取押金主线 FIN-03。退租验收也记在同一份证据里，因为两者共用 `deposit-ledger.util.ts`，必须串行。
