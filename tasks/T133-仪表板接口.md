# T133: 仪表板后端接口 + 前端接通

## 背景

后台首页（`frontend-admin/src/views/dashboard/index.vue`）此前是纯假数据：

- 统计卡片用 `setTimeout` 模拟
- 收入趋势、房源状态饼图为硬编码数值
- 其引用的 `/dashboard/stats`、`/dashboard/revenue-trend`、`/dashboard/room-status` 接口在后端完全不存在

同时发现前端请求层整体 404：`request.ts` 的 baseURL 缺少 `/api` 前缀，vite 代理 rewrite 又把 `/api` 剥掉，前后端路径对不上。

---

## 任务范围

### 后端：新增 dashboard 模块

1. `GET /api/dashboard/stats` — 统计卡片（房源/租客/合同/待缴账单/报修）
2. `GET /api/dashboard/revenue-trend?months=6` — 收入趋势（按 `PaymentRecord.paidAt` 归月汇总，单位：分，缺月补 0）
3. `GET /api/dashboard/room-status` — 房源状态分布（四种状态固定返回，缺省补 0）
4. 权限：仅 ADMIN（`JwtAuthGuard` + `RolesGuard`）
5. 单元测试（service + controller）

### 前端

6. `dashboard/index.vue` 接通真实接口，删除全部模拟数据
7. 修复 `request.ts` baseURL（默认 `/api`）与 `vite.config.ts` 代理 rewrite（保留 `/api` 前缀）

---

## 验收标准

1. ✅ 三个接口结构正确；未登录 401；非 ADMIN 403
2. ✅ 收入归月正确（烟测：8 月 50000 / 10 月 70000）
3. ✅ 后端 `tsc --noEmit` 通过；vitest 13 文件 84 用例全绿
4. ✅ 前端 `vue-tsc` + `vite build` 通过
5. ✅ 端到端烟测：注入数据 → 接口数值吻合 → 清理后归零
