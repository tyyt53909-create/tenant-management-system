# T225: 多角色小程序与维修工作台

## 背景

小程序目前只有租客与保洁两类工作台：`UserRole` 仅有 `ADMIN / CLEANER / TENANT`，报修工单只能由管理者在后台派单与流转，维修人员没有登录入口，也无法在手机上接单、填写处理结果。管理者派单时只能指派自己，无法选择维修人员。

本任务新增 `MAINTENANCE` 角色与维修工作台，并统一小程序的角色入口。工单分配同时支持两种模式：

- **公共池**：管理者把工单放入公共池，所有维修人员可见，先接先得；
- **定向指派**：管理者直接指定某位维修人员，该人员接单后处理。

## 范围

### 后端

- `UserRole` 新增 `MAINTENANCE`，新增数据库迁移（`ALTER TYPE`）。
- 员工邀请码注册：邀请码角色生效，`CLEANER / MAINTENANCE / ADMIN` 注册后不再创建 `Tenant` 档案。
- 报修工单：
  - `GET /maintenance/workbench`：维修人员工作台列表，支持 `view=pool|active|done`。
  - `GET /maintenance/workbench/:id`：维修人员工单详情（仅公共池或本人已接工单）。
  - `PATCH /maintenance/:id/claim`：接单（`ASSIGNED → IN_PROGRESS`，并发安全）。
  - `PATCH /maintenance/:id/complete`：提交处理结果（`IN_PROGRESS → PENDING_CONFIRM`，必须填写解决方案）。
  - `GET /maintenance/assignees`：管理员可指派的维修人员列表。
  - 管理员派单时 `assignedTo` 可省略，表示放入公共池；指定时校验为启用中的维修/管理员账号。
- 越权矩阵：维修人员不得访问租客/账单/合同/管理员接口；他人已接工单不可操作。

### 管理后台

- 邀请码目标角色新增 `CLEANER`、`MAINTENANCE`，列表角色标签正确显示。
- 报修处理弹窗支持「公共池」与维修人员列表，不再只能指派自己。
- 工单卡片显示「待接单（公共池）」状态提示。

### 小程序

- `openHome` 按角色分流：`CLEANER → 保洁工作台`、`MAINTENANCE → 维修首页`、其余 → 租客首页。
- 新增维修首页：工单概览、常用功能、最新待接单。
- 新增维修设置页：账号信息、通知提醒、主题设置、关于与退出登录。
- 新增 `RoleTabBar`：首页 / 工单 / 设置底部切换。
- 新增 `pages/maintenance/workbench`：待接单 / 进行中 / 已完成三个分页，下拉刷新、分页加载、未读数；列表卡片复用租客报修卡片。
- 复用租客 `pages/maintenance/detail`「报修进度」页：维修角色下显示接单与填写处理结果，租客仍看原时间轴。
- 工单列表只暴露房间、类别、优先级、描述与照片，不返回租客手机号等敏感资料。
- 租客端 `ensureTenantSession` 对任何非租客角色都跳转到对应工作台，避免误入租客页面。
