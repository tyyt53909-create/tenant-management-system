# T275：指标、金额格式与导出合并（FIN-10）

## 背景

ISS-34：统计口径分散——统计页按 `Bill.dueDate` 出账、仪表板按 `PaymentRecord.paidAt` 收入、管理摘要按全量账单 `amount/paidAmount`，「同一指标三种口径」且无文档；水电概览在无数据时回落到写死的演示数字。

ISS-44：前端金额格式化与 CSV 导出各写一套——`utils/table.ts` 的 `formatMoney`、视图内 `formatYuan`、`/100).toFixed(2)` 模板散落；`utils/csv.ts` 与 `utils/export.ts` 都导出 `downloadCsv` 但语义不同；`resourceCsv.ts` 再维护一份金额换算。

## 范围

### 1. 指标口径单一来源（后端）

- 新增 `backend/src/common/metrics/finance-metrics.ts`（纯函数）：
  - `sumAmounts(rows, pick)`、`collectionRate(billed, paid)`、`occupancyRate(occupied, total)`、`remainingAmount(billed, paid)`。
  - `bucketMonthlyRevenue(monthKeys, payments)`：按业务月归集收款，供仪表板趋势使用。
  - 导出 `METRIC_CALIBERS` 常量，声明每个指标的统计基准（出账=dueDate、收款=paidAt、出租率=区间末合同覆盖等）。
- `StatisticsService`、`DashboardService.getRevenueTrend`、`ManagementSummaryService` 改用共享函数；管理摘要响应增加 `caliber` 字段说明「全量、不含已取消账单」等口径。
- 不改变现有页面语义：统计页仍是区间报表，管理摘要是全量快照，差异通过字段与文档显式化，而不是强行合并成一个数。

### 2. 去掉演示指标回落（后端 + 前端）

- `MeterUsageQueryService.getUsageOverview` 删除 `isDemo` 与写死的用水/用电/成本/趋势演示值；无数据时返回 0 与 `hasData:false`。
- `frontend-admin` 水电概览卡片与趋势面板改读 `hasData`：无数据时显示「暂无抄表数据」，不再用 `?? 32.6` / `?? 13692` 之类硬编码兜底。

### 3. 金额格式单一来源（前端）

- 新增 `frontend-admin/src/utils/money.ts`：
  - `formatMoney(cents)`：`¥1,234.56`（千分位，现有行为）
  - `formatMoneyPlain(cents)`：`1234.56`
  - `centsToYuan(cents)` / `yuanToCents(yuan)`
  - `formatSignedMoney(cents)`：`+¥1.00` / `-¥1.00`
- `utils/table.ts` 改为从 `money.ts` 再导出，保持既有调用方兼容。
- 视图内重复的 `formatYuan` / `formatMoney` / `formatCents` 与模板里的 `/100).toFixed(2)` 统一改为 `money.ts`；不再手写除法。

### 4. 导出单一管道（前端）

- 合并 `utils/export.ts` 与 `utils/csv.ts`：
  - `toCsv` / `csvCell`（本地生成，保留公式注入防护）
  - `downloadCsv(content, fileName)`（本地 Blob 下载）
  - `downloadCsvFromServer(url, params, fileName)`（后端导出接口，统一错误提示）
- 删除 `utils/export.ts`，四个调用页面改 import；`resourceCsv.ts` 的金额换算改用 `yuanFromCents`。
- 后端继续复用 `common/utils/csv.util.ts` 与新的 `money.util.ts`；不新增第二套 CSV 生成器。

### 5. 文档与测试

- 新增 `docs/21-指标口径与金额格式.md`（事实来源类）：指标定义、时间基准、金额单位、导出管道；登记 `docs/INDEX.md`。
- 单元：`finance-metrics.spec.ts`、`money.spec.ts`、`csv.spec.ts`；更新统计/仪表板/管理摘要/水电概览用例。
- 集成：现有 `journeys` / `checkout` 回归即可；指标为只读聚合，不新增迁移。
