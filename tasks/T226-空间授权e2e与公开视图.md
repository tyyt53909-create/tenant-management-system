# T226: 空间授权 e2e 与公开视图

## 背景

T222 已完成 Space API 的伺服器端角色投影，但还没有 authorization e2e；T220 的公开页也还没有用空间 API 呈现可租房源分佈。

T226 补两个安全/公开交付：

1. `SPACE` / `floor-plans` 的角色授权矩阵。
2. 公开页的可租房源 2D 分佈小图。

## 前置

- 必读：`docs/16-房源模型接口契约.md`
- 必读：`backend/src/modules/space/*`
- 基线：`feature/T221-space-platform` @ `2adfdfd`
- 角色：ADMIN / CLEANER / TENANT / PUBLIC；TENANT 需有/无租客档案两种情况。

## 范围

### 后端授权 e2e

在 `backend/test/authorization.e2e-spec.ts` 增加：

- `GET /buildings/:id/space`：
  - ADMIN 200
  - CLEANER 200，且响应不含 tenantName/lease
  - TENANT 200，仅自己房间；无租客档案 403/空
  - 未登入 401
- `GET /buildings/:id/floor-plans`：
  - ADMIN 200
  - CLEANER / TENANT 403
  - 未登入 401
- `PUT /buildings/:id/floor-plans/:floor`：
  - CLEANER / TENANT 403
- 不修改现有测试断言，只新增 describe。

### 公开页

- `frontend-admin/src/views/public/index.vue` 增加「可租房源分佈」2D 小图。
- 新增 `frontend-admin/src/api/public.ts`（或扩展现有 public API）调用 `GET /public/buildings/:id/space`。
- 只显示 `RENTABLE` 房间；不含租客、租金、内部备注。
- 可复用 `SpacePlan2DContract`，但不要修改它。

## 验收

| # | 标准 | 验证 |
|---|---|---|
| 1 | ADMIN 可读取 space / floor-plans | authorization e2e |
| 2 | CLEANER 只取得任务房间且无租客/租金 | authorization e2e |
| 3 | TENANT 只取得自己房间 | authorization e2e |
