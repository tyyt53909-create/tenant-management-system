# T186: 文件存储抽象与缩略图（OPT-13）

依据优化计划 OPT-13。分支从 `feature/T185-structured-logs` 拉出。

## 行为

- `StorageAdapter` 提供 `put`、`get`、`delete`、`signedUrl`。
- `STORAGE_DRIVER=local` 写 `UPLOAD_DIR`。`s3` 使用 S3 兼容接口，可接阿里云 OSS 或 MinIO。
- 上传时检查文件头。声明的类型和内容不一致就拒绝。
- 每张图额外生成 `.thumb.jpg`。JPEG 原图和缩略图都会去掉 EXIF。
- 下载归属规则仍是：管理员可取任意文件，其他人只能取自己上传的，越权返回 404。

## 验收

- [x] 切换 `local` / `s3` 不改上传和下载的调用方式
- [x] 缩略图自动生成，GPS EXIF 不留在 JPEG 原图和缩略图里
- [x] 伪装成图片的文件被拒绝
- [x] 合同附件和归属测试仍然通过
