# T183: 定时任务多实例锁与 JobRun（OPT-10）

依据优化计划 OPT-10。分支从 `feature/T182-refresh-rotation` 拉出。

## 行为

- 每日任务、月度账单、通知清理都用 PostgreSQL 事务咨询锁包住。
- 抢不到锁的实例把 `job_runs.status` 写成 `SKIPPED`，不执行任务。
- 失败时写入最多 500 字的错误摘要。
- 管理员可用 `POST /scheduler/jobs/:name/run` 重跑。
- `notification-cleanup` 每天 01:20（Asia/Shanghai）删除创建超过 180 天的通知。

## 验收

- [x] 两个调用同时抢月度账单任务，只有一个执行
- [x] 成功、跳过、失败都会留下 JobRun
- [x] 超过 180 天的通知删除有单测
