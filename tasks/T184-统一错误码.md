# T184: 全局异常过滤器与统一错误码（OPT-11）

依据优化计划 OPT-11。分支从 `feature/T183-scheduler-lock` 拉出。错误码沿用 `docs/05` §5。

## 行为

- 4xx/5xx 都返回 `{ code, message, details?, requestId }`，并回写 `X-Request-Id`。
- Prisma `P2002` 返回 409 `COMMON_CONFLICT`。`P2025` 返回 404 `COMMON_RESOURCE_NOT_FOUND`。
- 未知错误记日志。生产环境的 500 只返回「服务器内部错误」，响应里没有堆栈或 SQL。
- 已知文案映射到 `AUTH_*`、`ROOM_*`、`BILL_*`、`PREPAY_*`、`CAPABILITY_DENIED`。
- 后台和小程序按 `code` 显示能力暂停、限流和内部错误。

## 验收

- [x] 错误 JSON 都带 `code` 和 `requestId`
- [x] 唯一键冲突返回 409
- [x] 生产环境 500 不泄露堆栈或 SQL
- [x] 前端按错误码提示
