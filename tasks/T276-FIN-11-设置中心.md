# T276：设置中心（FIN-11）

## 背景

FIN-11 要求把散落在环境变量、合同 JSON、前端常量里的业务默认值收进可审计的设置中心；T274 的 `MeterPriceHistory` 已支持「表类型默认价（`meterId IS NULL`）」，但没有任何写入口，导致新建电表必须逐块填价、调价无法统一。

当前缺口：

- 滞纳金规则只存在于每份合同的 `lateFeeRule` JSON，新合同默认空对象，每个合同都要手填。
- 预付账户预警阈值写死 `10000` 分，无法统一调整。
- 水电表单价没有类型级默认值入口（T274 已落数据模型，缺 API/UI）。
- 设置变更没有统一审计与类型校验。

## 范围

### 1. 设置模型与注册表

- 新增 `SystemSetting` 表（key 主键、JSON value、说明、更新人、时间）。
- 新增 `settings.registry.ts`：单一注册表声明 key、默认值、说明、归一化/校验函数。
- 首批 key：
  - `billing.defaultLateFeeRule`：新合同默认滞纳金规则（`graceDays` / `dailyRate` / `fixedDaily` / `cap`，金额分）。
  - `prepay.defaultLowBalanceThreshold`：新预付账户默认预警阈值（分，`0` 表示不提醒）。
- 未登记的 key 读/写一律 404 / 400，不接受任意 key 膨胀。

### 2. API 与审计

- `GET /settings`（ADMIN）：返回全部注册 key 的当前值、默认值、是否默认、更新人/时间。
- `GET /settings/:key`（ADMIN）。
- `PATCH /settings/:key`（ADMIN）：校验 + upsert + 审计（`UPDATE_SETTING`，before/after），返回归一化后的值。
- 所有写操作必须校验值类型与范围；不允许把字符串塞进金额、负数阈值或未知滞纳金字段。

### 3. 业务默认值接入

- 合同创建：`lateFeeRule` 为空（`undefined` / `{}`）时使用 `billing.defaultLateFeeRule`；显式传入仍优先。
- 预付账户创建：`lowBalanceThreshold` 为空时读取 `prepay.defaultLowBalanceThreshold`，`0` 保持为 0。
- 水电表类型默认价：
  - `GET /meters/price-defaults`：按表类型返回当前生效默认价（无则 `null`）。
  - `POST /meters/price-defaults`：写 `MeterPriceHistory(meterId=null)`，审计 `UPDATE_METER_DEFAULT_PRICE`。
  - `POST /meters` 的 `unitPrice` 改为可选：未传时取类型默认价，仍无则 400 并提示先配置设置中心。

### 4. 前端设置中心

- `settings/index.vue` 新增「业务设置」Tab：
  - 额金/滞纳金规则表单（宽限天数、按日费率、固定日额、封顶）。
  - 预付预警阈值（元输入，提交转分）。
  - 水电表默认价（水/电/燃气，元输入 + 生效日）。
- 统一使用 `utils/money.ts` 的 `yuanToCents` / `formatMoneyPlain`；保存成功后提示并刷新。
- 只对 ADMIN 显示；其它角色不新增入口（路由鉴权仍由全局守卫兜底）。

### 5. 测试与文档

- 单元：registry 归一化/边界、SettingsService 默认值/更新/审计、contracts/prepay/meters 接入默认值。
- 集成（真实 PostgreSQL）：设置往返、合同继承默认滞纳金、预付账户继承阈值、无单价建表使用类型默认价。
- 文档：`docs/02` 新增 `SystemSetting`、`docs/05` §7.6.7、`docs/21` 补充默认值来源、`docs/INDEX`。
- 任务书/证据/handoff 按模板补齐。

## 风险

- 默认滞纳金规则会影响所有新合同；上线前需确认默认值（空规则 = 不计收，保持现状）。
- 类型默认价只在建表未填单价时生效；已建表仍以自身价格历史为准，符合 T274 口径。
- 设置值缓存：不做进程内缓存，按请求读库；M2 单机规模可接受。
- 若生产库已有 `system_settings` 同名表，迁移使用 `CREATE TABLE IF NOT EXISTS` 并以 `IF NOT EXISTS` 建索引，保证可重复执行。
