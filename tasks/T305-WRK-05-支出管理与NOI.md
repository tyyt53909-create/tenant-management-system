# T305：支出管理与 NOI（含公区水电）

## 目标与已确认口径

依据 `docs/19-生产化路线图.md` 的 WRK-05，建立支出管理及经营净收入计算，覆盖公区水电。用户于 2026-10-29 确认第一版采用收付实现制：按实际收到的租金收入和实际支付的运营支出计算。金额按分，业务日期按 BusinessClock；财务记录不可硬删除。

## 已核实的设计约束

- `PaymentRecord` 带账单类型、收款本金/滞纳金分配、作废及冲正记录；计算租金净收入须明确收款、冲正与退款的归期和避免重复扣减，不能把押金或其他账单自动计入租金。
- `PublicUtilityBill` 可生成向租客分摊的账单，但没有实际支付日期或支付凭证字段；不能将抄表或生成单据视为已支付支出。应避免同一公区费用重复计入，保留来源关联与分摊可追溯性。
- 现有指标口径单一来源是 `docs/21-指标口径与金额格式.md`；新增计算前须同步定义和测试口径，不改动 human owner 文档。
- T324 水表备注标记修复尚待合入；任何依赖其正确性的路径必须按实际版本核验。

## 验收方向

- [ ] 确定支出录入、支付、作废/冲正、权限与数据范围的具体契约，公区水电真实支付与来源对应，避免重复计入。
- [ ] 租金收款、冲正及退款按已确认收付时间基准计算；测试跨期、押金及非租金排除、重复请求、并发与金额边界。
- [ ] 以真实 PostgreSQL 验证事务、约束与报表结果；按 expand/contract 串行迁移，不修改已有财务凭证或历史数据。
- [ ] 管理界面、API、权限、生成契约、事实文档及必要本地门禁；完成审查、CI、合入证据和交接后才能标记 completed。
