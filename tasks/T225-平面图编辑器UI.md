# T225: 平面图编辑器 UI

## 背景

T221 已完成 `FloorPlan` / `RoomShape` schema 与 `GET/PUT floor-plans`、模板产生 API。T225 只做 ADMIN 的前端编辑器，让管理员可以把 AUTO 示意图改成真实平面图。

## 前置

- 必读：`docs/16-房源模型接口契约.md`
- 必读：`frontend-admin/src/types/space.ts`
- 基线：`feature/T221-space-platform`（目前最新 `2adfdfd`）
- 后端 API 已存在；本机 dev DB 可能尚未套用 migration，浏览器验证失败时以 fixture/单元测试为准并回报。

## 范围

- 新增 `frontend-admin/src/api/floorPlans.ts`：
  - `getFloorPlans(buildingId)`
  - `saveFloorPlan(buildingId, floor, payload)`
  - `createFloorPlanTemplate(buildingId, floor)`
- 新增 `frontend-admin/src/views/space/editor.vue`：
  - 楼栋 / 楼层选择
  - 模板产生
  - SVG 画布显示 RECT/POLYGON
  - 拖曳移动、缩放、对齐网格
  - 未放置房间列表
  - 保存、版本冲突 409 提示、重新载入
- 可新增 `frontend-admin/src/components/space/editor/*` helper / 子组件。
- 在 `router/index.ts` 加 `/space/editor` 路由。
- 在 `views/space/index.vue` 加入「编辑平面图」入口（只允许这一处小改）。
- 不改后端、不改 `SpacePlan2DContract` / `SpaceScene3DContract` / package。
