# T301：到期提醒、续约意向与续约报价（LSE-04）

## 背景与目标

根据生产化第二轮路线图（`docs/19-生产化路线图.md`）M4（全生命周期与协作）规划以及解决遗留缺陷 **ISS-20（无到期提醒；holdover 未处理）**，系统需要推进合同到期生命周期闭环管理：

1. **合同到期梯次提醒（Expiring Reminders）**：
   - 定时调度器对即将到期的生效中合同进行 30天、15天、7天梯次扫描与预警；
   - 支持幂等去重防重复扰民，通过 `NotificationsService`（含微信订阅消息与站内信）引导租客填报续约意向。
2. **租客续约意向收集（Renewal Intent）**：
   - 新增 `RenewalIntent` 实体，租客在移动端表达续约意愿（续租、不续租、考虑中）、期望租期、期望月租与备注留言；
   - 管理端汇总查看即将到期合同的意向流转与跟进状态。
3. **管理端续约报价单与租客确认闭环（Renewal Offer）**：
   - 新增 `RenewalOffer` 实体，管理员可针对即将到期合同发起定制化续约报价（优惠租金、押金、续约起止期、折扣特惠说明、报价有效期）；
   - 租客端可查看报价详情、接受报价或拒绝报价；租客接受报价后，自动联动创建续签合同草稿（复用 `renew` 逻辑并继承共同承租人）。
4. **到期滞留（Holdover）监控（ISS-20）**：
   - 检测已到期（EXPIRED）但房源仍处于 OCCUPIED、既未续签也未退租的滞留合同，提供监控列表以便管家线下催促与跟进。
5. **真实数据库测试与全门禁**：
   - 编写 `backend/test/integration/contract-renewal.int-spec.ts` 真实数据库集成测试（BE-INT）；
   - 更新 OpenAPI 规范并对齐小程序 API 与前端类型，通过全部 CI 门禁。
