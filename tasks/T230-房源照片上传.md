# T230：房源照片上传

## 背景

后台「房源档案」新增/编辑房源时只能填写房号、楼层、房型、面积与设施，无法上传房源照片。
数据库已有 `RoomPhoto` 表，详情面板与公开看房页也已能展示 `photos`，但缺少录入入口。

本任务补齐：在 `/rooms` 的新增/编辑房源对话框中上传、排序、删除照片，并随房源保存。

## 范围

- 后端 `CreateRoomDto` / `UpdateRoomDto` 接受 `photos` 数组；`POST /rooms`、`PATCH /rooms/:id` 原子写入/替换 `room_photos`。
- 照片地址只接受 `/api/files/` 上传结果，最多 20 张；数组顺序即 `sortOrder`，第一张为封面。
- 前端新增房源 / 编辑房源对话框增加照片编辑器：上传、左移、右移、删除、失败提示。
- 编辑时从 `GET /rooms/:id` 读取已有照片；保存后详情面板与公开看房页复用既有展示。
- 不改 Room 表结构、不改上传接口，不引入新依赖。

## 验收

| # | 标准 | 验证 |
|---|---|---|
| 1 | 新增房源可上传照片并保存，重新打开详情可见 | API + Playwright |
| 2 | 编辑房源可加载已有照片、调整顺序、删除后保存 | API + Playwright |
| 3 | 最多 20 张；仅 JPG/PNG/WebP；单张 ≤10MB | DTO/单元测试 |
| 4 | 非 `/api/files/` 地址、超过 20 张被后端拒绝 | DTO 测试 |
| 5 | 照片顺序持久化为 `sortOrder`，首张为封面 | 服务测试 |
| 6 | 后端 lint/build/test、前端 lint/build/test 通过 | CI |
