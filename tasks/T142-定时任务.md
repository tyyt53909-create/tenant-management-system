# T142: 定时任务（合同流转 / 逾期检查 / 账单提醒 / 报修自动确认 / 预付提醒 / 月度账单）

## 背景

`docs/04-状态机.md` 定义了 5 处自动流转、`docs/02-数据模型.md` 定义了月度账单生成与归档策略，`docs/08-任务拆分总览.md`（T212/T224）列为待开发。此前所有「系统自动」均为空白：合同不会自动生效/到期、账单不会自动逾期、滞纳金建议不会自动产生、提醒不存在、报修不会自动确认、预付低余额无提醒。本任务以 `@nestjs/schedule`（ADR-001 已定）补齐自动化底座。

## 任务范围

### 定时任务（每日常规，Asia/Shanghai 凌晨 1:00）

1. **合同自动流转**（docs/04 §2.4）：
   - DRAFT 且生效日到达 → ACTIVE；房间若为 RESERVED 随动 OCCUPIED（version 递增，保护人工房态）
   - ACTIVE 且到期日已过 → EXPIRED + 租客到期提醒（无账号则跳过通知）
2. **逾期检查**（docs/04 §3.4）：PENDING/PARTIAL 到期未缴 → OVERDUE；未缴金额 > 0 时刷新滞纳金建议（已确认 409 跳过）；发送逾期提醒（URGENT）
3. **账单提醒**（待确认清单 #6）：到期前 3 天 / 到期日 / 逾期 1、3、7 天；同一收件人同日同标题去重
4. **报修自动确认**（docs/04 §4.4）：PENDING_CONFIRM 超 3 天无响应 → COMPLETED（resolvedAt + 结论文案）
5. **工单优先级升级**（docs/04 §4.4）：SUBMITTED + NORMAL 超 3 天 → URGENT
6. **预付低余额提醒**：余额低于阈值且今日未提醒 → 通知 + 更新 `lastNotifiedAt`（每账户每日最多一次）

### 月度任务（Asia/Shanghai 每月 1 日 01:10）

7. **月租金账单生成**（docs/02）：ACTIVE + MONTHLY 循环且未到期合同 → 当月租金账单（快照租金/paymentDay/合同号）+ 收租提醒；同合同同账期幂等跳过

### 手动触发（运维/测试）

8. `POST /scheduler/run-daily`、`POST /scheduler/run-monthly-bills`（ADMIN）

## 决策记录

- **时区**：固定 `Asia/Shanghai`（项目单区域部署）；日期比较统一按 UTC 日历日（与 `@db.Date` 存储一致）
- **月度账单范围**：v1 仅 MONTHLY 循环合同（QUARTERLY/ANNUAL 需期数逻辑，留待按需扩展）
- **账单生成走 `BillsService.create`**：复用账单号生成与校验；幂等由「同合同 + RENT + 同账期」查重保证
- **提醒去重**：按「收件人 + 标题 + 当日」查通知表，避免每日任务重复提醒（逾期 1 天提醒与逾期检查的通知共用标题，天然去重）
- **报修自动确认按 `updatedAt` 超 3 天**（文档口径）；升级按 `createdAt` 超 3 天
- **单项任务隔离**：runDaily 聚合执行，单项失败记录 errors 不影响其他任务
- **通知失败不阻断**：发送异常仅告警（租客可能未注册账号，不视为任务失败）
