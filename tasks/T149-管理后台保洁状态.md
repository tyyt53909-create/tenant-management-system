# T149 管理后台保洁状态视图

## 目标

## 交付物
- `frontend-admin/src/utils/roomStatus.ts`：房态 / 清洁状态的中文标签与配色映射。
- `views/rooms/index.vue`：展示 `cleanStatus` 列（CLEAN / PENDING_CLEAN / CLEANING）并支持待清洁筛选。
- `views/cleaning/`：独立保洁视图，配套路由与菜单入口。
- 同步 `MainLayout`、`router`、`stores/user`、`types`、`api/rooms`、`views/login`。
