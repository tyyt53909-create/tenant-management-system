# T221: 平面图数据模型与编辑 API

## 背景

T220 已交付 ADMIN 的自动示意 2D/3D 模型。T221 新增真实平面图的数据基础：

- 每层可有 `FloorPlan`（画布尺寸、版本、底图）。
- 每个房间可有 `RoomShape`（矩形或多边形）。
- 支援模板产生、读取、保存与乐观锁。

本任务只处理 schema、migration 与后端 CRUD，不改 2D/3D renderer。

## 前置

- 必读：`docs/16-房源模型接口契约.md`
- 必读：`/Users/Admin/.opencode/plan/06-房源模型并行开发计划.md`
- 基线：`feature/T221-space-platform`

## 范围

- `FloorPlan` / `RoomShape` / `ShapeKind` Prisma model。
- Migration（唯一可修改 `backend/prisma/migrations` 的任务）。
- `backend/src/modules/floor-plans/`：
  - `GET /buildings/:id/floor-plans`
  - `PUT /buildings/:id/floor-plans/:floor`
  - `POST /buildings/:id/floor-plans/:floor/template`
- 只允许 ADMIN；版本冲突 409。
- 一个 `RoomShape` 只能绑定一个房间；允许 `roomId = null` 预留槽位。
- 测试：CRUD、版本冲突、重复绑定、权限、模板产生。

## 验收

| # | 标准 | 验证 |
|---|---|---|
| 1 | migration 可在干净数据库套用 | `npx prisma migrate dev` / CI |
