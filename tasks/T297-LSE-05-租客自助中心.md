# T297：租客自助中心（LSE-05）

## 背景与目标

根据生产化路线图（docs/19 里程碑 M3），在完成微信体系接入（一键登录 WX-01、服务与订阅通知 WX-02、短信通道 WX-03）、线上支付闭环（JSAPI 收款 PAY-01、原路退款与对账 PAY-02、防伪电子收据与 PDF PAY-03）后，建设**租客自助中心（LSE-05）**，打通租客全生命周期自助服务闭环：

1. **居住全景与自助服务聚合看板**：
   - 在小程序个人中心 / 居住中心全面升级租客自助工作台。
   - 展现有效合同租期、专属管家联系方式、待缴账单汇聚、预付账户余额、报修处理进度及实名认证状态。
   - 提供全功能自助金刚区：快捷缴费、在线报修、预付充值、我的电子收据、退租结算单、防伪验真工具。
2. **线上直接缴费与电子收据凭证全链路接入**：
   - 账单详情（`bill-detail`）无缝集成微信支付 JSAPI（PAY-01）：待缴账单直接一键调起微信收银台；亦保留生成线下转账单据图片发送给房东的双通道。
   - 已缴/部分缴纳账单支持直接查看官方电子收款收据（`GET /api/bills/:id/receipt`），呈现大写金额与防伪校验码；支持单笔收款收据凭单查看。
   - 电子收据一键生成并本地打开标准 PDF（`GET /api/bills/:id/receipt/pdf`），通过小程序原生 `downloadFile` 与 `openDocument` 预览与保存分享。
3. **收据中心与公开防伪验真工具**：
   - 提供专属收据列表与凭证查询，展示所有收款收据记录、防伪码与作废状态。
   - 接入防伪验真工具，支持租客扫码或输入收据编号即时在线查验凭单真伪与有效性。
4. **实名认证与登记自助查看与提交（SEC-08 / ISS-22）**：
   - 扩展租客端实名登记接口：允许租客查询本人实名认证状态（`GET /api/tenants/me/registration`），并支持租客自助提交证件信息与实名认证（`POST /api/tenants/me/registration`）。
   - 严格遵循 SEC-08 隐私安全与脱敏规则，全流程加密存储与操作审计。
5. **退租结算凭单自助查询**：
   - 提供退租结算凭单查看入口，租客可查看结算金额、退款状态与退租单据。
6. **门禁与测试保障**：
   - 补充后端单元测试、覆盖率检查（保持全量达标）、真实 PostgreSQL 集成测试与小程序组件/页面测试。
   - 保证 OpenAPI 契约更新、代码检查与文档规范全绿。

## 验收标准
