## 任务目标

在种子数据脚本中添加默认楼栋（Building）和管理员账号的初始化逻辑，确保系统启动后可以正常使用。

---

## 任务范围

### 必须完成
1. 创建默认楼栋（从配置读取ID）
2. 创建管理员账号
3. 生成管理员的邀请码（供测试使用）
4. 确保幂等性（多次运行不会重复创建）

### 不包括
- 业务数据初始化（房间、租客等由用户后续创建）

## 详细实现步骤

### 步骤1：更新 seed.ts

编辑 `backend/prisma/seed.ts`：

```typescript
import { PrismaClient } from '@prisma/client';
import * as bcrypt from 'bcrypt';

const prisma = new PrismaClient();

async function main() {
  console.log('🌱 开始种子数据初始化...');

  // 1. 创建默认楼栋
  const DEFAULT_BUILDING_ID = process.env.DEFAULT_BUILDING_ID || 'building-001';
  
  const building = await prisma.building.upsert({
    where: { id: DEFAULT_BUILDING_ID },
    update: {},
    create: {
      id: DEFAULT_BUILDING_ID,
      name: '默认楼栋',
      floors: 7,
      metadata: {
        landlordName: '管理员',
        description: '系统默认楼栋',
      },
      isActive: true,
    },
  });
  
  console.log('✅ 默认楼栋已创建:', building);

  // 2. 创建管理员账号
  const adminEmail = process.env.ADMIN_EMAIL || 'admin@example.com';
  const adminPassword = process.env.ADMIN_PASSWORD || 'Admin@123';
  
  const passwordHash = await bcrypt.hash(adminPassword, 10);
  
  const admin = await prisma.user.upsert({
    where: { email: adminEmail },
    update: {},
    create: {
      email: adminEmail,
      passwordHash,
      role: 'ADMIN',
      isActive: true,
    },
  });
  
  console.log('✅ 管理员账号已创建:', { email: adminEmail });
  console.log('⚠️  请记住密码:', adminPassword);

  // 3. 生成测试用邀请码
  const testInviteCode = `INVITE-${Date.now()}`;
  
  await prisma.user.update({
    where: { id: admin.id },
    data: {
      inviteCode: testInviteCode,
      inviteExpiredAt: new Date(Date.now() + 365 * 24 * 60 * 60 * 1000), // 1年后过期
    },
  });
  
  console.log('✅ 测试邀请码已生成:', testInviteCode);

  console.log('🎉 种子数据初始化完成！');
}

main()
  .then(async () => {
    await prisma.$disconnect();
  })
  .catch(async (e) => {
    console.error('❌ 种子数据初始化失败:', e);
    await prisma.$disconnect();
    process.exit(1);
  });
```
