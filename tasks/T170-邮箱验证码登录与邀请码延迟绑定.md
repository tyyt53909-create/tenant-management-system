# T170: 邮箱验证码登录与邀请码延迟绑定

## 1. 任务背景
在租客端（H5与小程序）原先的注册登录流程中，存在要求用户在登录门槛前必须提供管理员邀请码或预设密码的限制，增加了普通租客的使用阻力。
本任务对租客端登录逻辑进行重构：
1. **免门槛登录**：将登录首选方式切换为「**邮箱验证码登录 (OTP)**」与「**Google 快捷登录**」，首次登录免密自动创建租客账户；
2. **邀请码延迟绑定**：将邀请码角色从“登录门禁”转变为“应用内房源与身份关联凭证”。用户登录后，可在个人中心随时输入管理员提供的邀请码，完成房源、房间与租赁合同的绑定与激活。

## 2. 目标与范围
- **后端服务 (NestJS)**：
  - `EmailOtpService`：
    - 基于 `nodemailer` 实现邮件验证码派发能力。
    - 6 位随机验证码、5 分钟有效生命周期、60 秒防刷冷却频控。
    - 生产环境对接 SMTP 邮件网关；开发与测试模式支持日志直出及 `123456` 万能测试码。
  - `AuthController` 接口扩充：
    - `POST /api/auth/send-email-code`：发送验证码并返回冷却时间。
    - `POST /api/auth/login-email-code`：校验验证码，已有用户登录；新用户自动在事务中创建 User 与 Tenant 档案，如有未绑定的同邮箱预建租客自动完成关联。
    - `POST /api/auth/bind-invite-code`：登录后输入邀请码，校验有效性并在事务中清空邀请码、关联当前用户 `invitedBy`。
    - `POST /api/auth/google`：支持新用户零门槛自动注册登录，解除强制要求邀请码的门槛。
    - `GET /api/auth/me`：补充返回 `invitedBy` 以及租客名下有效合同与房间信息。
- **租客端 (Miniprogram H5)**：
  - `miniprogram/api/index.js`：封装 `sendEmailCode`、`loginWithEmailCode`、`bindInviteCode`。
  - `miniprogram/pages/login/login.vue`：
    - 改造为 Tab 模式：默认首选「验证码免密登录」（带 60s 倒计时器），保留「密码登录」为备选。
    - 保持「Sign in with Google」第三方快捷登录入口。
    - 页面提供新用户免密入驻与应用内绑定邀请码的指引。
  - `miniprogram/pages/profile/profile.vue`：
    - 未绑定房源时展示醒目的「🔑 绑定房源邀请码」横幅卡片。
    - 菜单栏增设「房源与邀请码绑定」入口。
    - 点击唤起专属弹窗输入邀请码，绑定成功后自动刷新名片与房源信息。
