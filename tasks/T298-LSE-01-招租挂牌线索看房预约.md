# T298：招租挂牌、意向线索、看房预约与分享卡片（LSE-01）

## 背景与目标

根据生产化第二轮路线图（`docs/19-生产化路线图.md`）M4 里程碑规划以及附录 A 问题清单 **ISS-46（无挂牌价、线索、看房预约）**，系统需要补齐从公域/私域意向引流到带看签约的招租全生命周期起点闭环：

1. **房源挂牌与价格管理**：
   - 在房间实体 `Room` 增加挂牌价（`listingPrice`，单位：分）、挂牌上架状态（`isListed`，默认 true）、预计起租日期（`availableDate`）；
   - 更新管理端创建/编辑房间 DTO；公开房源接口（`GET /api/public/rooms` / `GET /api/public/rooms/:id`）白名单暴露挂牌价格与上架状态。
2. **意向线索（Leads）留资与管线**：
   - 新增 `Lead`（意向线索）实体与迁移，记录客户姓名、手机号、意向房型、预算区间、期望入住时间、来源渠道（`source`）、状态（`NEW`, `FOLLOWING`, `CONVERTED`, `CLOSED`）与管家跟进备注；
   - 暴露公开留资接口 `POST /api/public/leads`（限流防护、防注入与脱敏）；
   - 暴露管理端线索列表与状态跟进流转接口（`GET /api/leads`, `PATCH /api/leads/:id`）。
3. **看房预约（ViewingAppointment）生命周期与排期**：
   - 新增 `ViewingAppointment` 实体与迁移，包含关联房源、看房人姓名、手机号、预约时间段（`appointmentTime`）、看房人数、状态（`PENDING`, `CONFIRMED`, `COMPLETED`, `CANCELLED`）、管家确认人与带看反馈；
   - 暴露访客/租客预约申请端点 `POST /api/public/appointments`（免登录或携带用户 Token）；
   - 暴露管理端预约确认排期、完工与取消接口（`PATCH /api/appointments/:id/confirm`, `complete`, `cancel`）；
   - 预约成功与确认排期触发 `NotificationDispatcher` 发送通知提醒。
4. **房源分享卡片与空间平面图联动（T240）**：
   - 暴露房源分享卡片接口 `GET /api/public/rooms/:id/share`，生成微信小程序分享卡片参数与海报格式化元数据；
   - 关联 `FloorPlan` / `RoomShape` 返回空间平面图方位与户型结构信息。
5. **真实数据库测试与全门禁**：
   - 编写 `backend/test/integration/listing-leads-viewing.int-spec.ts` 真实数据库集成测试（BE-INT）；
   - 单元测试覆盖率达标、小程序与前端 API 同步、OpenAPI 契约无漂移。

## 验收标准

- [x] `Room` 实体支持挂牌价格 `listingPrice`、挂牌开关 `isListed` 与起租日期 `availableDate`，公开房源接口安全呈现。
- [x] 访客可免登录提交意向线索（`POST /api/public/leads`），管理端可查询与跟进线索生命周期。
- [x] 访客可发起看房预约（`POST /api/public/appointments`），管理端可确认排期、记录带看反馈或取消，状态机严密。
- [x] 提供房源分享卡片数据端点，支持与空间平面图坐标联动。
- [x] 全套单元测试与真实 PostgreSQL 数据库集成测试通过。
- [x] OpenAPI 契约同步无漂移，通过所有 CI 质量门禁。
