# T224: 3D 空间渲染器

## 背景

T220 已有 Three.js 等軸模型，但目前只消費舊的 `spaceModel.ts`，且幾何是自動示意。T224 把 3D renderer 升級成契約 v1，支援 AUTHORED 幾何、alerts、未放置房間與更大規模。

## 前置

- 必读：`docs/16-房源模型接口契约.md`
- 必读：`frontend-admin/src/types/space.ts`
- 必读：`frontend-admin/src/utils/__fixtures__/spaceModel.fixture.ts`
- 基线：`feature/T221-space-platform`
- 後端 API 未完成前，使用 fixture。

## 范围

- 新增 `frontend-admin/src/components/space/SpaceScene3DContract.vue`：
  - 消費契約 v1；
  - RECT 挤出、POLYGON 挤出；
  - 六態材質、alerts 視覺；
  - 樓層隔離、展開/合攏、重置視角；
  - hover / click / selected；
  - WebGL fallback；
  - dispose、render-on-demand；
  - 162+ 房間效能。
- 可新增 `frontend-admin/src/components/space/space3dContract.ts` 放幾何/材質 helper。
- 保留既有 `SpaceScene3D.vue` 給 T220 頁面使用，不能讓 `/space` build 壞掉。
- 不改 `spaceModel.ts`、page/router/API。
