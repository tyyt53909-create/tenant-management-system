# T215: 租客标签管理

## 背景

`docs/00-项目计划书.md` §2.1「必做功能」与 §3.3 第 2 周任务均列有「租客管理：档案 CRUD、**标签管理**」。
复查时发现该项**完全缺失**：

- `Tenant.tags` 只有 `Json?` 列，表单没有输入、列表没有展示与筛选、没有任何校验
- 计划书其余 P0/P1 项均已完成，这是第一版范围里唯一未交付的功能

## 范围

| 项 | 内容 |
|---|---|
| 数据模型 | 新增 `Tag`（字典）与 `TenantTag`（关联）两张表；删除 `Tenant.tags` JSON 列 |
| 数据迁移 | 把既有 `Tenant.tags` 字符串数组回填为字典与关联，非字符串数组忽略 |
| 后端 | `/tags` 增删改查；租客创建/更新接受 `tagIds`；列表支持 `?tagId=` 筛选；响应返回 `{ id, name }[]` |
| 管理后台 | 租客表单多选标签、列表标签列与筛选、详情抽屉展示、「系统设置 › 标签字典」维护页 |
| 测试 | 后端单测（标签校验、清空、筛选、摊平）、`TagsService` 单测、越权矩阵（3 角色 × 读写） |

## 不在范围

- 租客端（小程序）不展示标签：标签是管理侧分类工具，租客无业务需求
- 标签包（层级、颜色）：当前只有名称与排序

## 验收标准（每条都可用命令验证）

| # | 标准 | 验证方式 |
|---|---|---|
| 1 | 迁移可在空库与带旧数据的库上执行 | 空库 `migrate deploy`；带 `tags` 数组的库执行后 `tenant_tags` 行数等于有效字符串项 |
| 2 | 标签不存在时创建/更新返回 400 且不写库 | `tenants.service.spec.ts`「标签不存在 → 400，且不写库」 |
| 3 | 更新未传 `tagIds` 不改标签；传 `[]` 清空 | 同名单测两条 |
| 4 | 列表可按 `tagId` 筛选 | `tenants.service.spec.ts`「列表可带 tagId 筛选」 |
| 5 | 三种角色读 `/tags`、仅 ADMIN 可写 | `backend/test/authorization.e2e-spec.ts`「标签字典（T215）」5 条 |
| 6 | 前端类型、构建、单测、lint 全绿 | `vue-tsc -b`、`vite build`、`npm test`、`oxlint` |
| 7 | 后端类型、构建、lint 全绿，OpenAPI 无漂移 | `tsc -p tsconfig.build.json`、`nest build`、`oxlint`、`npm run openapi:check` |
| 8 | 文档表数与 schema 一致 | `node scripts/check-docs.js` |
