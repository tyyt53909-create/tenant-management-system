# T228: 房源模型视觉重做

## 背景

用户反馈 T220/T223/T224 的 3D 过于平面、不像一栋楼，且多栋楼没有「小区模型 → 点楼栋 → 2D 楼层」的层级。

T228 重做空间视图的视觉与信息架构：

- 单栋楼：一栋可旋转的建筑模型，房间在楼层内。
- 多栋楼：小区模型，点击楼栋进入该栋 2D 楼层。
- 颜色：绿色=可租/无人；红色=待清洁/清洁中/维修；蓝色=已租；紫色=已预订。

## 范围

- `SpaceCampus3D.vue`：小区模型、楼栋块、标签、点击进入。
- `SpaceScene3DContract.vue`：单栋建筑外壳、屋顶边框、楼板、房间、展开/合拢。
- `views/space/index.vue`：campus/building 视图状态、楼栋列表、返回小区、摘要。
- 颜色语义同步：`spaceModel.ts`、`spaceContractModel.ts`、`space3dContract.ts`。
- 后端 AUTO 布局改为 2～8 栏、尽量接近方形，避免 3D 变成薄片。
- 平面图 2D 的 layoutLabel 本地化。

## 验收

| # | 标准 | 验证 |
|---|---|---|
| 1 | 单栋楼默认显示 3D 建筑模型，房间可见 | 浏览器截图 |
| 2 | 多栋楼默认显示小区模型，标签显示可租/已租 | 浏览器截图 |
| 3 | 点击楼栋进入该栋 2D 楼层 | Playwright |
| 4 | 绿色可租、蓝色已租、红色待处理 | 图例/截图 |
