# T321：会话撤销原子化（R03 / SEC-02）

用户会话索引改为 Redis Set，写入和撤销用 Lua 一次完成。撤销会写下围栏。撤销前创建的会话血统不能在撤销完成后写回。撤销之后的新登录仍可建立会话。Redis 命令失败会抛出，不假装撤销成功。

Access Token 在过期前仍然有效。发布规范还没有确认必须立即作废 Access Token，所以这轮没有加 Access 黑名单。
