# T282：实时推送：WebSocket + 轮询后备（COM-02）

## 范围

- 后端 Socket.IO `/notifications` 网关：Access Token 鉴权、按用户房间推送。
- `NotificationsService.create` 落库后推送；无 WS server 时静默。
- 管理后台连接与断线轮询后备（30s 未读数）。
- 单测：鉴权、房间、emit、无 server；文档 `docs/27-实时推送.md`、docs/05/12/INDEX。

- 前端仅刷新未读数，不直接展示消息体，避免权限绕过。
