# T223: 2D 空间渲染器

## 背景

T220 已有 `/space` 的 2D SVG 剖面，但目前只消費前端 `spaceModel.ts` 的舊形狀，且沒有 AUTHORED 幾何、alerts、未放置房間等契約能力。

T223 把 2D renderer 升級成契約 v1 的第一個正式 renderer，並作為 3D 的幾何參考。

## 前置

- 必读：`docs/16-房源模型接口契约.md`
- 必读：`frontend-admin/src/types/space.ts`
- 必读：`frontend-admin/src/utils/__fixtures__/spaceModel.fixture.ts`
- 基线：`feature/T221-space-platform`
- 後端 API 未完成前，使用 fixture。

## 范围

- 新增 `frontend-admin/src/utils/spaceContractModel.ts`：
  - 把契約 v1 轉成 renderer 使用的模型；
  - 支援 AUTO / AUTHORED / MIXED；
  - 保留房號自然排序、六態、summary；
  - 對 `unplaced` 房間提供明確顯示。
- 新增 `frontend-admin/src/components/space/SpacePlan2DContract.vue`：
  - RECT / POLYGON；
  - alerts 徽章；
  - 鍵盤選中；
  - 878px 無橫向滾動；
  - 空樓層、未放置房間；
  - 長房號尾碼截斷 + 完整 title。
- 保留既有 `spaceModel.ts` / `SpacePlan2D.vue` 給 T220 頁面使用，不能讓 `/space` build 壞掉。
- 單元測試：adapter、六態、AUTO/AUTHORED、長房號、空樓層。
- 不改 3D、不改 page/router/API。
