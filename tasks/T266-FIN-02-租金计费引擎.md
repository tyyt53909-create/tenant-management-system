# T266：租金计费引擎（FIN-02）

## 目标

修复 ISS-14：按月、季、半年、年四种付款周期在自然周期起始月生成 RENT 账单；合同首期从生效日开始按周期实际天数折算，账单按合同和 period 幂等。

## 实现

- 以**合同起始月**为锚点，每 `cycleMonths`（1/3/6/12）个月生成一次 RENT 账单；不再按自然年 1/4/7/10 月。
- 账单 period = 周期起始月 `YYYY-MM`；snapshot 记录 `cycle`、`periodStart`、`periodEnd`、`proratedDays`。
- 首期从合同起始日、末期截到合同结束日，按「实际在租天数 / 周期天数」折算，四舍五入到分。
- 到期日 = 周期起始月 `paymentDay`（clamp 28），UTC 日期。
- 幂等：同合同 + RENT + period 已有账单则跳过；仍委托 `BillsService.create`。
- 保持 `generateMonthlyBills` 方法名与通知去重键，调度器调用端不变。

## 验收

- 周期起始月生成账单，其他月份跳过；period 使用周期起始月 `YYYY-MM`。
- 快照保存周期、周期起止日及计费天数；到期日按 UTC 起始月 paymentDay 并 clamp 到 28。
- 保持 `generateMonthlyBills` 方法和通知去重键；账单创建仍委托 `BillsService.create`。
- 单元测试覆盖四种周期、合同起始月锚点、首期/末期折算、已有账单跳过和非起始月。

## 实施范围

仅 scheduler 月度账单服务及其单元测试；不修改 schema 或 BillsService。
