# T300：入住/退租验房与租客退租申请（LSE-03）

## 背景与目标

根据生产化路线图（`docs/19-生产化路线图.md`）M4（全生命周期与协作）里程碑规划，租约在履约过程中需要打通实物交接与退租申请两项核心业务环节：

1. **入住验房与交付清单（Check-in Inspection）**：
   - 合同签约或生效入住时，管家与租客对照设备与设施清单逐项核验（门锁、电器、家具、卫浴等），记录状态、照片与水电气底数；
   - 租客端可查看本人的入住交付清单并确认签字或填写意见，作为起租房屋实物依据。
2. **租客自主发起退租申请（Tenant Checkout Request）**：
   - 租客在小程序/移动端对生效中合同自主发起退租申请，填写期望退租日、退租原因与退款收款账号；
   - 租客可在审批前主动撤回；管理端可审核通过或驳回并填报原因；审核通过可联动生成退租单草稿（`CheckoutRecord`）。
3. **退租验房与交接单（Check-out Inspection）**：
   - 退租时生成退租交接验房单，对比入住底数记录水电表退租读数；
   - 核验物品损坏与遗失情况并估算维修赔偿金额，可作为退租结算扣款（`DEPOSIT_DEDUCTION`）的实物依据。
4. **设置中心联动（FIN-11）与数据安全（SEC-07）**：
   - 预设默认验房清单模板及提前退租天数参数；
   - 验房照片与附件受数据隔离保护，租客端访问严格通过 `scopedWhere` 防越权。
