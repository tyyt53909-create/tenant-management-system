# T190: 类型安全治理（OPT-17）

依据优化计划 OPT-17。分支从 `feature/T189-split-services` 拉出。

## 目标

1. 消除所有 `$executeRawUnsafe` / `$queryRawUnsafe`，替换为 Prisma 原生参数化模板 `$queryRaw` / `$executeRaw`。
2. 引入 `@CurrentUser()` 自定义参数装饰器与强类型 `AuthUser` 接口（id, email, phone, role 等），替换各个 Controller 中的 `@Request() req: any` 与 `req.user`。
3. 全面治理 Controller 与 Service 中的 `where: any` 动态过滤，替换为 `Prisma.XxxWhereInput` 精确类型。
4. 全面治理异常捕获中的 `catch (err: any)`，替换为 `catch (err: unknown)` 并安全提取错误信息。
5. 将 `backend/src`（不含测试与外部库）中的 `any` 数量从 140 处压缩至 15 处以内，且剩余的 `any` 均有明确注释说明合理性。
6. 保持 `npm test`（652 个后端单测）、`npm run lint`（oxlint）、`npm run openapi:check`、miniprogram 测试全部全绿通过。

## 验收标准

- [x] `any` 少于 15 处，非测试代码达成 0 处 `any`
- [x] 没有 `$executeRawUnsafe` / `$queryRawUnsafe`（0 处）
- [x] `tsc --noEmit` 与 oxlint 0 错误
- [x] 既有测试全部通过无断言修改，OpenAPI 契约无漂移（118 条路由一致）
