# T168: 电子收款收据与退租结算凭单

## 1. 任务背景
在租务管理现实运营中，租客线下支付或补缴水电费后需要纸质/电子收据存根作为付款证明；租客办理退租离店时，需要由管家和租客双方签署「退租结算凭单」，白纸黑字列明押金退还与各项扣费依据。

## 2. 目标与范围
- **中文大写人民币换算工具**：
  - `backend/src/common/utils/currency.util.ts`：将分为单位的金额精准转为财务标准大写人民币（如 `300000` -> `叁仟元整`，`12345` -> `壹佰贰拾叁元肆角伍分`），支持零分、角分连续零等 edge case。
- **后端单据快照接口**：
  - `GET /bills/:id/receipt`：生成标准收款收据快照（收据编号、付款人、房间、楼栋、账期、账单类型、本金/滞纳金、付款流水明细、人民币大写）。
  - `GET /checkout-records/:id/voucher`：生成结算单凭据快照（凭单编号、租客信息、合同租期、退租日期、结算项明细列表、退款/扣款合计、净退款大写、处理人）。
- **前端高保真打印凭据弹窗**：
  - `ReceiptModal.vue`：优雅票据排版、虚线凭证框、印章占位区、`@media print` 样式（打印时仅输出凭证区域，隐藏导航与按钮）。
  - `SettlementVoucherModal.vue`：详细列明租金退还/押金退还/押金扣除/水电余额退还/其他费用清单，附带双方签字确认栏。
