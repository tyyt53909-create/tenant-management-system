# T138: 小程序对接修复（baseURL / 登录字段 / 报修 / 余额页）

## 背景

小程序从未真实运行过：baseURL 缺 `/api` 导致**全部请求 404**；另有登录字段、报修 ID、余额页字段等多处与后端不一致。本任务逐项修复，并顺带收紧后端越权。

---

## 任务范围

### 小程序修复（4 个文件）

1. `utils/request.js`：`BASE_URL` 补 `/api` 前缀（此前所有请求 404）
2. `pages/login/login.vue`：登录改发 `identifier`（后端 DTO 字段；此前发 `account` → 400）
3. `pages/maintenance/maintenance.vue`：删除硬编码 `roomId: 'room-001' / tenantId: 'tenant-001'`，改由服务端推导
4. `pages/account/account.vue`：
   - 余额字段 `balance` → `balanceCache`（此前永远显示 0）
   - 流水字段 `transactionType` → `type`；金额显示按符号处理（负数不再双重负号）
   - 类型映射对齐数据库枚举（RECHARGE/DEDUCTION/REFUND/ADJUSTMENT）

### 后端（maintenance 模块）

5. 新增 `GET /maintenance/my`（TENANT，仅自己的工单，分页倒序）——小程序此前调用的缺失接口
6. `POST /maintenance` 改造：
   - 守卫 `@Roles('TENANT', 'ADMIN')`
   - **租客自助报修：tenantId 取自登录身份、roomId 取自生效合同；忽略请求体中的 ID（防伪造）**
   - 管理员保持显式传 ID；未传 → 400
7. 安全收紧：`GET /maintenance`（全部）改为 ADMIN-only；`GET /:id` 租客仅能查自己的（否则 404）
8. `CreateMaintenanceDto`：`roomId`/`tenantId` 改为可选

### 测试

9. `maintenance.service.spec.ts`（模块此前零测试）：10 例（含伪造 ID 忽略、无合同 400、越权 404）
10. DTO 测试扩展 3 例（T138 场景）
