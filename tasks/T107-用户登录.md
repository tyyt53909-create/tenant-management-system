## 任务目标

实现用户登录接口，支持邮箱或手机号登录，验证密码，返回 JWT Token，并更新最后登录时间。

---

## 任务范围

### 必须完成
1. POST /auth/login 登录接口
2. 支持邮箱或手机号登录
3. 密码验证（bcrypt.compare）
4. 返回 JWT Token
5. 更新最后登录时间（lastLoginAt）
6. LoginDto 定义
7. 单元测试

### 登录流程
1. 接收邮箱/手机号 + 密码
2. 查询用户（邮箱或手机号）
3. 验证用户是否存在且激活
4. 验证密码（bcrypt.compare）
5. 生成 JWT Token
6. 更新最后登录时间
7. 返回 Token 和用户信息
