# T208: 排程、部署与 CI 修复（全专案审查第三轮）

修复审查中「定时任务算错 / 生产工件起不来 / CI 埋雷 / 刷新令牌并发」一类已确认缺陷。

## 验收标准

- [x] 逾期天数与提醒全部按「业务日」计算（凌晨 01:00 上海执行不再算成逾期 0 天）；新增回归测试，已验证在修复前代码上会失败。
- [x] 逾期提醒的去重键带节点维度（1/3/7 天不再互相吞掉）；同日去重窗口改用 UTC 自然日零点；通知发送失败不再计入 `sent`。
- [x] 月账单生成逐个合同隔离失败，且有失败时任务以失败收尾（`job_runs` 记 FAILED）。
- [x] 咨询锁事务 timeout 覆盖任务时长（不再 5 秒后释放锁并记 FAILED）。
- [x] Dockerfile 增加「Prisma 引擎必须与运行架构一致」的构建期断言；本地重建镜像验证产出 arm64 引擎且引擎可加载。
- [x] 三个 CI workflow 的 `ENCRYPTION_KEY` 改为合法 32 字节（原 30 字节，一碰加密就抛错）。
- [x] refresh 轮换改为原子（`rotate` compare-and-set）；并发刷新不再撤销整个会话家族，仅在超出 30 秒宽限窗口时按重放处理。
- [x] 后端 819 测例 / e2e 34 例全绿；tsc/lint/build/openapi:check/docs-check 全过。
- [x] 交接记录 `docs/handoff/2026-10-18-T208-排程部署与CI修复.md` 并在 `docs/INDEX.md` 注册。
