# T176: 水电表模拟器生产隔离（OPT-03）

依据优化计划 OPT-03。不新增业务功能。

## 行为

- `FEATURE_METER_SIMULATOR` 默认关闭。未设为 `true` 时，`POST /api/meters/simulator/run` 返回 404。
- `GET /api/auth/me` 返回 `features.meterSimulator`。后台入口按这个值显示。
- 模拟读数 `source = SIMULATED`。用量概览、未结算预览和周期结算都不计入。
- 手工录入和设备上报的自动结算规则不变。模拟读数默认不自动扣费。

## 验收

- [x] 开关关闭时接口 404，后台入口不显示
- [x] 开关打开时，用量统计和结算查询带 `source != SIMULATED`
- [x] `.env.example` 与 `docs/12-部署与运维.md` 登记该开关
