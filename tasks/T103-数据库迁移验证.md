## 任务范围

2. 创建新的初始迁移

4. 验证所有表创建成功
5. 验证外键关系
6. 验证索引创建

---

## 详细实现步骤

### 步骤1：删除旧迁移

```bash
cd backend
rm -rf prisma/migrations/*
```

### 步骤2：创建初始迁移

```bash
npx prisma migrate dev --name init_core_tables
```

### 步骤3：运行种子数据

```bash
npm run prisma:seed
```

### 步骤4：验证表结构

```bash
# 打开 Prisma Studio 验证
npm run prisma:studio
```

检查：
- 所有24张表都存在
- Building 表有1条记录
- User 表有1条管理员记录
