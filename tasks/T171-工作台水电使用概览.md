# T171: 首页工作台水电使用概览（UTILITIES / USAGE OVERVIEW）

## 1. 任务背景

长租公寓日常运营中，水电费抄表与能耗是高频、琐碎且关乎资金结清的核心环节。在完成 T166 批量抄表工作台后，管理者需要在工作台首页（Dashboard）集中掌握各楼栋的水电消耗、费用估算、抄表完成度以及近 6 个月用量趋势。

根据设计稿原型规范，在管理后台工作台新增「水电使用概览」全功能卡片组件。

## 2. 功能清单

### 后端能力
- `GET /meters/usage-overview`：
  - 查询参数：`buildingId`（可选）、`month`（`YYYY-MM`，默认当前月）
  - 返回数据：
    - `water`: `{ usage, momRate, count }`（本月累计用水 m³、较上月环比率、已登记读数次数）
    - `electricity`: `{ usage, momRate, count }`（本月累计用电 kWh、较上月环比率、已登记读数次数）
    - `cost`: `{ total, waterCost, electricityCost }`（估算总费用、水费、电费）
    - `completion`: `{ completedMeters, totalMeters, pendingMeters, status }`（该月抄表完成度，待抄表数，状态）
    - `trend`: 近 6 个月用水与用电量历史聚合，含月度用量与费用
    - `isDemo`: 是否包含平滑演示回落数据
- 完整的单元测试覆盖（`meters.service.spec.ts` 与 `meters.controller.spec.ts`）

### 前端能力
- 新增组件 `frontend-admin/src/components/dashboard/UtilitiesOverviewCard.vue`：
  - 顶部标头：`UTILITIES / USAGE OVERVIEW` 英文顶标、标题、状态徽标、楼栋筛选下拉、月份选择器、一键跳转 `/meters`
  - 四大 KPI 卡片：
    - 鼠尾草绿顶边：本月累计用水（m³ / 吨）+ 环比状态
    - 暖琥珀色顶边：本月累计用电（kWh / 度）+ 环比状态
    - 橄榄绿顶边：估算水电费（总计、水费明细、电费明细）
    - 陶土红顶边：该月抄表完成度（已抄/总表数、待抄表高亮）
  - 近六个月用量趋势图：
    - 用电（kWh）/ 用水（m³）快捷切换
    - 当前月用量大字号与环比提要
    - ECharts 平滑面积渐变折线图
- 嵌入 `frontend-admin/src/views/dashboard/index.vue`
- 前端测试与构建验证通过
