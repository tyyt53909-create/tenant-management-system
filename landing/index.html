资金闭环

钱从哪进来、扣到哪去，系统自己记得

每一笔钱，都能自己对上账

三条链路彼此咬合：账单收款、预付充值扣费、水电读数扣费。每个资金动作都带幂等键，重复提交不会重复入账。

你交了多少、扣了多少、还剩多少，系统里的数字和你手上的记录是同一个。

  1. 01

    账单收款

    合同 → 月度账单 → 收款登记 → 状态联动

    账单金额取自合同快照，收款后自动在待缴 / 部分缴 / 已缴清 / 逾期之间流转；重复的交易号会被拒绝。

  2. 02

    预付充值扣费

    充值 → 余额 → 扣费 → 余额不足提醒 → 生成补缴账单

    水电走预存制，扣费必须发生在余额之内；余额触到阈值先提醒，不够的部分转成一张待缴账单。

  3. 03

    水电读数扣费

    抄表 → 用量 × 单价 → 自动扣费 → 差额补缴

    本期读数减上期读数得到用量，乘单价后自动入流水，单价按生效日期留存历史，改价不影响旧账。

  1. 01

    账单明细

    账期 · 金额 · 到期日 · 状态

    哪个月、多少钱、什么时候到期、交没交，四个字段说完整，不用翻群聊。

  2. 02

    余额与流水

    充值 → 扣费 → 退款 → 余额

    每一笔变动带时间、事由和变动后的余额，能一路推回到上一次充值。

  3. 03

    退租结算

    押金 → 扣除项 → 折算租金 → 退款

    扣了什么、按什么算，逐条列出来；退款走确认流程，不是一句话带过。

房态状态机

报修全流程

一个房间从空到满，每一步都有据可依

报修不是发个消息，而是一条能追的工单

提交后进入「已提交」，管理员受理、派单、维修，完成前还会回到你这里确认。 中间每一步的状态和照片都留在工单里。

技术底座

数据在自己手里，权限在服务端收口

一套可以自托管的系统：本地 Docker Compose 起数据库就能跑，也可以部署到自己的云主机。

技术选型

  • NestJS 12TypeScript 严格模式的后端框架
  • Prisma + PostgreSQL 16类型安全查询，25 张表
  • Redis会话与缓存
  • Vue 3 + Element Plus管理后台
  • uni-app 微信小程序租客端与保洁端

安全与合规

  • JWT 鉴权 + 角色守卫管理 / 租客 / 保洁三类角色分权
  • 按楼栋隔离跨楼栋数据默认不可见
  • 审计日志记录操作人、动作、前后变化与来源 IP
  • 文件归属校验上传登记归属，下载前校验，避免越权取件
  • 生产环境种子守卫默认账号不允许进入生产库

部署与上线

  • Docker Compose 或云服务PostgreSQL 16 + Redis 起本地环境；生产指向 RDS / 云 Redis
  • 迁移只前滚生产用 prisma migrate deploy，不重置、不推送结构
  • 密钥不进仓库JWT_SECRET ≥32 字节、ENCRYPTION_KEY 32 字节，缺失即启动失败
  • 备份云数据库每日快照保留 30 天；上线前做一次恢复演练
  • 上线自检类型检查、oxlint、全量测试、端到端 27 项、文档检查

常见问题

上线前最常被问到的几件事

答不上来的不写。下面是已经有确定答案的。

数据放在哪里？可以自己部署吗？

可以自己部署。开发环境用 Docker Compose 起 PostgreSQL 16 与 Redis；生产可以指向阿里云 RDS、 Redis 与 OSS，也可以整套放在自己的服务器上。数据库和 Redis 不需要对公网暴露， 由 Nginx 终止 TLS 后只转发 /api。

这些功能现在真的能跑吗？

能跑，但边界写清楚：房源与房态状态机、租客与合同、账单收款、滞纳金与核销、预付账户流水、 水电读数扣费、报修工单、退租结算、通知、定时任务、统计报表、公开看房页、保洁两端都已跑通。 覆盖率门禁、真机验收和生产部署还在推进中，智能水电表、在线支付、短信、电子签章、 电子发票与存量数据导入都还没做——完整清单见上面的「项目现状」。

租客和保洁不会用怎么办？

用微信小程序，不用装 App、不用记新密码。登录后每个人只看得到自己那部分：租客看自己的账单、 余额、报修和合同，保洁只看待清洁与清洁中的房间。关怀版主题会把字号整体放大， 长辈也能看清楚。

能从 Excel 或旧系统把数据迁过来吗？

暂时不能批量导入，存量数据导入还在规划中。目前是在后台手工建立楼栋、房间与合同， 已经入住的租客按现有档案补录。如果你的存量规模较大，这件事需要在上线前单独排期。

欠费和滞纳金是怎么处理的？

系统按合同里约定的规则（宽限天数、按日比例或固定金额、封顶）算出建议金额， 需要人工确认或减免之后才会入账。它不会自动从租客账户扣钱，也不会自动生成一笔收款—— 钱怎么收、收多少，决定权始终在人手上。

权限是前端藏一下，还是服务端真的拦？

服务端真的拦。角色守卫、按楼栋隔离、文件下载的归属校验都在后端；前端不显示只是顺手， 绕过前端直接调接口同样会被拒绝。每次增删改都会写审计日志，记录操作人、动作、 前后变化和来源 IP。
