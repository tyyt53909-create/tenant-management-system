# 租客管理系统 - 租客小程序

> **T145 构建说明（2026-10-13）**：安装、API 环境变量、构建输出及风险以 [小程序构建与配置](../docs/11-小程序构建与配置.md) 为准。使用 `npm ci`；生产构建必须设置 HTTPS `VITE_API_BASE_URL`（带 `/api`）。下方为早期功能说明，不代表支付、Token 自动刷新、图片上传或真机验收已完成。

## 项目简介

基于 uni-app 开发的租客端小程序，为租客提供便捷的租房管理服务。

## 技术栈

- uni-app 3.x
- Vue 3
- 微信小程序

## 功能模块

### 1. 首页
- 用户信息展示
- 快捷功能入口
- 待办事项提醒
- 最近账单

### 2. 账单管理
- 账单列表（全部/待支付/已支付）
- 账单详情
- 在线支付（待开发）

### 3. 在线报修
- 报修列表
- 创建报修（标题、类别、优先级、描述、图片）
- 报修状态跟踪

### 4. 个人中心
- 我的合同
- 账户余额
- 联系客服
- 退出登录

## 开发指南

### 安装依赖

```bash
npm install
```

### 开发运行

#### 微信小程序
```bash
npm run dev:mp-weixin
```

然后使用微信开发者工具打开 `dist/dev/mp-weixin` 目录

#### H5
```bash
npm run dev:h5
```

### 生产构建

```bash
npm run build:mp-weixin
```

## 配置说明

### API 基础地址

修改 `utils/request.js` 中的 `BASE_URL`：

```javascript
const BASE_URL = 'http://localhost:3000'  // 本地开发
// const BASE_URL = 'https://api.example.com'  // 生产环境
```

### 微信小程序 AppID

修改 `manifest.json` 中的 `mp-weixin.appid`

## 常见问题

### 1. 无法连接后端
- 检查后端服务是否启动
- 检查 `BASE_URL` 配置是否正确
- 微信小程序需要在"详情-本地设置"中勾选"不校验合法域名"

### 2. 登录失败
- 检查账号密码是否正确
- 检查后端 API 是否正常

### 3. 图片上传失败
- 图片上传功能暂未完成
- 需要配置 OSS 服务
